### 🚀 Quick Commands (Top Priority)

```bash
# Получение данных о сертификатах домена в формате JSON (Suppress output)
curl -s https://crt.sh/\?q\=<DOMAIN>\&output\=json | jq .

# Извлечение и фильтрация уникальных поддоменов из ответа crt.sh
curl -s https://crt.sh/\?q\=<DOMAIN>\&output\=json | jq . | grep name | cut -d":" -f2 | grep -v "CN=" | cut -d'"' -f2 | awk '{gsub(/\\n/,"\n");}1;' | sort -u

# Определение хостов, размещенных компанией (фильтрация по IP)
for i in $(cat <WORDLIST>);do host $i | grep "has address" | grep <DOMAIN> | cut -d" " -f1,4;done

# Сбор списка IP-адресов для сканирования через Shodan
for i in $(cat <WORDLIST>);do host $i | grep "has address" | grep <DOMAIN> | cut -d" " -f4 >> ip-addresses.txt;done

# Проверка собранных IP-адресов через Shodan
for i in $(cat ip-addresses.txt);do shodan host $i;done

# Получение всех доступных DNS-записей (ANY query)
dig any <DOMAIN>
```

### 🛠 Tools & Utilities

*   [[curl]] — Утилита для передачи данных с использованием различных протоколов (HTTP, HTTPS, FTP и др.).
*   [[jq]] — Легковесный и гибкий процессор JSON-данных из командной строки.
*   [[host]] / [[dig]] — Утилиты для запросов к DNS-серверам (входит в пакет `bind-utils`).
*   [[Shodan]] — Поисковая система для устройств, постоянно подключенных к Интернету.
*   [[grep]] / [[cut]] / [[awk]] / [[sort]] — Стандартные Unix-утилиты для обработки и фильтрации текста.

### 📝 Technical Analysis & Media

Сбор информации о домене (Domain Information Gathering) — ключевой компонент любого тестирования на проникновение. Этот процесс включает не только перечисление поддоменов (subdomain enumeration), но и оценку всего присутствия организации в сети (internet presence). Мы собираем информацию, чтобы понять функциональность компании, а также оценить необходимые технологии и структуры, используемые для предоставления ее услуг.

> [!info] Пассивный сбор информации (Passive Reconnaissance)
> Этот тип информации собирается пассивно, без прямого и активного сканирования целевых систем. Мы действуем как "клиенты" или "посетители", избегая прямых связей с компанией, которые могли бы нас раскрыть.
> 
> Разделы, посвященные OSINT (Open Source Intelligence), описывают лишь часть доступных методов. Для углубленного изучения рекомендуется модуль [OSINT: Корпоративная разведка](https://academy.hackthebox.com/course/preview/osint-corporate-recon).

При пассивном сборе информации мы используем сторонние сервисы. Однако первым шагом всегда является тщательное изучение основного веб-сайта компании. Анализ текстов и предлагаемых услуг позволяет определить, какие технологии и структуры необходимы для работы этих сервисов (например, разработка приложений, IoT, хостинг, IT-безопасность).

Например, анализ услуг представляет собой комбинацию принципов **first principle** и **second principle** перечисления (enumeration). Мы обращаем внимание на то, что «мы видим» (сервисы) и что «мы не видим» (их внутренняя функциональность). Сервисы связаны с определенными техническими аспектами, которые мы можем вывести, рассматривая все с позиции разработчика.

### Прозрачность сертификатов (Certificate Transparency)

Еще один источник для поиска поддоменов — [crt.sh](https://crt.sh/). Этот ресурс содержит журналы **прозрачности сертификатов** (Certificate Transparency, CT).

> [!info] Certificate Transparency
> CT — это процесс, предназначенный для проверки выданных цифровых сертификатов для зашифрованных интернет-соединений. Стандарт ([RFC 6962](https://tools.ietf.org/html/rfc6962)) предусматривает ведение журналов, подтверждающих подлинность всех цифровых сертификатов, выданных центром сертификации (CA). Это позволяет обнаруживать поддельные или злонамеренно выданные сертификаты для домена. Поставщики, такие как Let's Encrypt, передают эти данные в веб-интерфейс [crt.sh](https://crt.sh/).

Запрос к crt.sh для `<DOMAIN>`:

`https://www.crt.sh/?q=inlanefreight.com`
