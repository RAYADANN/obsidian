В конце предыдущего раздела мы установили сессию командной оболочки с целью. Изначально наша оболочка была ограничена (иногда её называют «тюремной оболочкой»), поэтому мы использовали Python для запуска оболочки TTY Bourne, чтобы получить доступ к большему количеству команд и командной строке. Вероятно, мы будем всё чаще сталкиваться с подобной ситуацией по мере практики на Hack The Box и в реальных боевых действиях.

```
`perl -e 'exec "/bin/sh";'`
`perl: exec "/bin/sh";`

`ruby: exec "/bin/sh"`

`lua: os.execute('/bin/sh')`

`awk 'BEGIN {system("/bin/sh")}'`

`find / -name nameoffile -exec /bin/awk 'BEGIN {system("/bin/sh")}' \;`

`find . -exec /bin/sh \; -quit`

`vim -c ':!/bin/sh'`

`vim :set shell=/bin/sh :shell`
```


Иногда мы сталкиваемся с системой с ограниченными возможностями командной оболочки, где Python не установлен. В таких случаях полезно знать, что можно использовать несколько различных методов для запуска интерактивной оболочки. Давайте рассмотрим некоторые из них.

Следует помнить, что всякий раз, когда мы видим `/bin/sh`или `/bin/bash`, это также может быть заменено исполняемым файлом, связанным с языком интерпретатора оболочки, присутствующим в данной системе. В большинстве систем Linux мы, скорее всего, встретим `bourne shell`( `/bin/sh`) и `bourne again shell`( `/bin/bash`), присутствующие в системе изначально.

## /bin/sh -i

Эта команда выполнит указанный в пути интерпретатор оболочки в интерактивном режиме ( `-i`).

#### Интерактивный

        shellsession
`/bin/sh -i sh: no job control in this shell sh-4.2$`

---

## Perl

Если в системе установлен язык программирования [Perl](https://www.perl.org/) , эти команды выполнят указанный интерпретатор оболочки.

#### Perl в оболочку

`perl -e 'exec "/bin/sh";'`

`perl: exec "/bin/sh";`

Приведенную выше команду следует запускать из скрипта.

## Руби

Если в системе установлен язык программирования [Ruby](https://www.ruby-lang.org/en/) , эта команда выполнит указанный интерпретатор оболочки:

#### Рубин в Шелл

        shellsession
`ruby: exec "/bin/sh"`

Приведенную выше команду следует запускать из скрипта.

## Два

Если в системе установлен язык программирования [Lua](https://www.lua.org/)`os.execute` , мы можем использовать метод для выполнения указанного интерпретатора оболочки, используя приведенную ниже полную команду:

#### Lua To Shell

        shellsession
`lua: os.execute('/bin/sh')`

Приведенную выше команду следует запускать из скрипта.

---

## AWK

[AWK](https://man7.org/linux/man-pages/man1/awk.1p.html) — это язык сканирования и обработки шаблонов, похожий на C, присутствующий в большинстве систем на базе UNIX/Linux и широко используемый разработчиками и системными администраторами для создания отчетов. Его также можно использовать для запуска интерактивной оболочки. Это показано в приведенном ниже коротком скрипте awk:

#### AWK To Shell

        shellsession
`awk 'BEGIN {system("/bin/sh")}'`

---

## Находить

[Команда `find`](https://man7.org/linux/man-pages/man1/find.1.html) присутствует в большинстве систем Unix/Linux и широко используется для поиска файлов и каталогов по различным критериям. Она также может использоваться для запуска приложений и интерпретатора командной оболочки.

#### Использование функции «Найти» для командной оболочки

        shellsession
`find / -name nameoffile -exec /bin/awk 'BEGIN {system("/bin/sh")}' \;`

В данном случае команда find ищет любой файл, указанный после `-name`параметра, затем выполняет `awk`( `/bin/awk`) и запускает тот же скрипт, который мы обсуждали в разделе awk, для запуска интерпретатора оболочки.

---

## Использование команды `exec` для запуска оболочки.

        shellsession
`find . -exec /bin/sh \; -quit`

В этом случае команда `find` использует опцию `execute` ( `-exec`) для непосредственного запуска интерпретатора оболочки. Если `find`указанный файл не найден, то доступ к оболочке не будет получен.

---

## ПОТОМУ ЧТО

Да, мы можем установить язык интерпретатора оболочки из популярного текстового редактора, работающего через командную строку `VIM`. Это очень специфическая ситуация, в которой нам может понадобиться этот метод, но полезно знать на всякий случай.

#### Vim To Shell

        shellsession
`vim -c ':!/bin/sh'`

#### Я пришел в Escape

        shellsession
`vim :set shell=/bin/sh :shell`

## Вопросы, касающиеся прав доступа к исполняемым файлам.

Помимо знания всех перечисленных выше параметров, следует помнить о правах доступа, которыми обладает учетная запись в рамках сеанса оболочки. Всегда можно попробовать выполнить эту команду, чтобы вывести список свойств файлов и прав доступа, которыми обладает наша учетная запись для любого файла или исполняемого файла:

#### Разрешения

        shellsession
`ls -la <path/to/fileorbinary>`

Мы также можем попробовать выполнить эту команду, чтобы проверить, какие `sudo`права доступа есть у учетной записи, на которую мы попали:

#### Судо-л

        shellsession
`sudo -l Matching Defaults entries for apache on ILF-WebSrv:     env_reset, mail_badpass,    secure_path=/usr/local/sbin\:/usr/local/bin\:/usr/sbin\:/usr/bin\:/sbin\:/bin User apache may run the following commands on ILF-WebSrv:     (ALL : ALL) NOPASSWD: ALL`

Для выполнения команды sudo -l, указанной выше, потребуется стабильная интерактивная оболочка. Если вы находитесь не в полноценной оболочке или в нестабильной, вы можете не получить никакого результата. Учет прав доступа позволит нам не только увидеть, какие команды мы можем выполнять, но и может дать представление о потенциальных путях повышения привилегий.
