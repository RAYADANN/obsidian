| **Командование** | **Описание**                                                                                                                                                                                                                                                                                                                                               |
| ---------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `dpkg`           | Это `dpkg`инструмент для установки, сборки, удаления и управления пакетами Debian. Основной и наиболее удобный для пользователя интерфейс для него `dpkg`— aptitude.                                                                                                                                                                                       |
| `apt`            | Apt предоставляет высокоуровневый интерфейс командной строки для системы управления пакетами.                                                                                                                                                                                                                                                              |
| `aptitude`       | Aptitude — это альтернатива apt и представляет собой высокоуровневый интерфейс к менеджеру пакетов.                                                                                                                                                                                                                                                        |
| `snap`           | Устанавливайте, настраивайте, обновляйте и удаляйте пакеты Snap. Snap-пакеты обеспечивают безопасное распространение новейших приложений и утилит для облачных сервисов, серверов, настольных компьютеров и интернета вещей.                                                                                                                               |
| `gem`            | Gem — это интерфейс для RubyGems, стандартного менеджера пакетов для Ruby.                                                                                                                                                                                                                                                                                 |
| `pip`            | Pip — это установщик пакетов Python, рекомендуемый для установки пакетов Python, недоступных в архиве Debian. Он может работать с системами контроля версий (в настоящее время только с репозиториями Git, Mercurial и Bazaar), ведет подробный лог-файл и предотвращает частичную установку, загружая все необходимые компоненты перед началом установки. |
| `git`            | Git — это быстрая, масштабируемая, распределенная система контроля версий с необычайно богатым набором команд, обеспечивающая как высокоуровневые операции, так и полный доступ к внутренним механизмам.                                                                                                                                                   |
