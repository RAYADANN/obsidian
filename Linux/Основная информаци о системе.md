| **Командование** | **Описание**                                                                                                                          |
| ---------------- | ------------------------------------------------------------------------------------------------------------------------------------- |
| `whoami`         | Отображает текущее имя пользователя.                                                                                                  |
| `id`             | Возвращает идентификационные данные пользователей.                                                                                    |
| `hostname`       | Устанавливает или выводит имя текущей хост-системы.                                                                                   |
| `uname`          | Выводит основную информацию о названии операционной системы и аппаратном обеспечении системы.                                         |
| `pwd`            | Возвращает имя рабочей директории.                                                                                                    |
| `ifconfig`       | Утилита ifconfig используется для назначения или просмотра адреса сетевому интерфейсу и/или настройки параметров сетевого интерфейса. |
| `ip`             | IP-адрес — это утилита для отображения или управления маршрутизацией, сетевыми устройствами, интерфейсами и туннелями.                |
| `netstat`        | Отображает состояние сети.                                                                                                            |
| `ss`             | Ещё одна утилита для исследования сокетов.                                                                                            |
| `ps`             | Отображает статус процесса.                                                                                                           |
| `who`            | Отображает, кто вошел в систему.                                                                                                      |
| `env`            | Выводит информацию об окружении или задает и выполняет команду.                                                                       |
| `lsblk`          | Отображает список блочных устройств.                                                                                                  |
| `lsusb`          | Список USB-устройств                                                                                                                  |
| `lsof`           | Список открытых файлов.                                                                                                               |
| `lspci`          | Отображает список устройств PCI.                                                                                                      |
