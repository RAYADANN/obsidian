## Философия

Философия Linux основана на простоте, модульности и открытости. Она выступает за создание небольших, узкоспециализированных программ, хорошо выполняющих одну задачу. Эти программы можно комбинировать различными способами для выполнения сложных операций, что повышает эффективность и гибкость. Linux следует пяти основным принципам:

| **Принцип**                                                   | **Описание**                                                                                                                                                                            |
| ------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `Everything is a file`                                        | Все конфигурационные файлы для различных служб, работающих в операционной системе Linux, хранятся в одном или нескольких текстовых файлах.                                              |
| `Small, single-purpose programs`                              | Linux предлагает множество различных инструментов, с которыми мы будем работать, и которые можно комбинировать для совместной работы.                                                   |
| `Ability to chain programs together to perform complex tasks` | Интеграция и сочетание различных инструментов позволяют нам выполнять множество масштабных и сложных задач, таких как обработка или фильтрация конкретных результатов обработки данных. |
| `Avoid captive user interfaces`                               | Linux разработан для работы преимущественно с командной оболочкой (или терминалом), что дает пользователю больший контроль над операционной системой.                                   |
| `Configuration data stored in a text file`                    | Примером такого файла является `/etc/passwd`файл, в котором хранятся данные обо всех пользователях, зарегистрированных в системе.                                                       |

## Компоненты

|**Компонент**|**Описание**|
|---|---|
|`Bootloader`|Фрагмент кода, который запускается для управления процессом загрузки операционной системы. Parrot Linux использует загрузчик GRUB.|
|`OS Kernel`|Ядро — это основной компонент операционной системы. Оно управляет ресурсами для устройств ввода-вывода системы на аппаратном уровне.|
|`Daemons`|Фоновые службы в Linux называются «демонами». Их задача — обеспечить корректную работу ключевых функций, таких как планирование, печать и мультимедиа. Эти небольшие программы загружаются после загрузки или входа в систему компьютера.|
|`OS Shell`|Оболочка операционной системы или интерпретатор командного языка (также известный как командная строка) — это интерфейс между ОС и пользователем. Этот интерфейс позволяет пользователю указывать ОС, что нужно делать. Наиболее часто используемые оболочки — это Bash, Tcsh/Csh, Ksh, Zsh и Fish.|
|`Graphics server`|Это обеспечивает работу графической подсистемы (сервера), называемой "X" или "X-сервер", которая позволяет запускать графические программы локально или удаленно в системе X-окна.|
|`Window Manager`|Также известна как графический пользовательский интерфейс (GUI). Существует множество вариантов, включая GNOME, KDE, MATE, Unity и Cinnamon. Рабочая среда обычно включает в себя несколько приложений, в том числе файловый и веб-браузеры. Они позволяют пользователю получать доступ к основным и часто используемым функциям и службам операционной системы и управлять ими.|
|`Utilities`|Приложения или утилиты — это программы, которые выполняют определенные функции для пользователя или другой программы.|

## Архитектура Linux

Операционная система Linux может быть разделена на слои:

|**Слой**|**Описание**|
|---|---|
|`Hardware`|Периферийные устройства, такие как оперативная память системы, жесткий диск, центральный процессор и другие.|
|`Kernel`|Ядро операционной системы Linux, функция которого заключается в виртуализации и управлении общими ресурсами компьютерного оборудования, такими как ЦП, выделенная память, доступные данные и другие. Ядро предоставляет каждому процессу собственные виртуальные ресурсы и предотвращает/смягчает конфликты между различными процессами.|
|`Shell`|Интерфейс командной строки ( **CLI** ), также известный как оболочка, в которую пользователь может вводить команды для выполнения функций ядра.|
|`System Utility`|Предоставляет пользователю доступ ко всем функциям операционной системы.|

## Иерархия файловой системы

Операционная система Linux имеет древовидную иерархическую структуру и описана в стандарте [иерархии файловых систем](http://www.pathname.com/fhs/) (FHS). В структуру Linux входят следующие стандартные каталоги верхнего уровня:

![Диаграмма иерархии файловой системы Linux с корневым каталогом, разветвляющимся на папки: /bin, /boot, /dev, /etc, /lib, /media, /mnt, /opt, /home, /run, /root, /proc, /sys, /tmp, /usr, /var.](https://cdn.services-k8s.prod.aws.htb.systems/content/modules/18/NEW_filesystem.png)

|**Путь**|**Описание**|
|---|---|
|`/`|Каталог верхнего уровня является корневым каталогом файловой системы и содержит все файлы, необходимые для загрузки операционной системы до монтирования других файловых систем, а также файлы, необходимые для загрузки других файловых систем. После загрузки все остальные файловые системы монтируются в стандартные точки монтирования в качестве подкаталогов корневого каталога.|
|`/bin`|Содержит необходимые исполняемые файлы команд.|
|`/boot`|Состоит из статического загрузчика, исполняемого файла ядра и файлов, необходимых для загрузки операционной системы Linux.|
|`/dev`|Содержит файлы устройств, облегчающие доступ ко всем аппаратным устройствам, подключенным к системе.|
|`/etc`|Локальные системные конфигурационные файлы. Здесь также можно сохранять конфигурационные файлы установленных приложений.|
|`/home`|У каждого пользователя в системе здесь есть подкаталог для хранения данных.|
|`/lib`|Файлы разделяемых библиотек, необходимые для загрузки системы.|
|`/media`|Сюда устанавливаются внешние съемные носители информации, такие как USB-накопители.|
|`/mnt`|Временная точка монтирования для обычных файловых систем.|
|`/opt`|Здесь можно сохранять дополнительные файлы, такие как файлы сторонних инструментов.|
|`/root`|Домашний каталог пользователя root.|
|`/sbin`|В этой директории находятся исполняемые файлы, используемые для администрирования системы (двоичные системные файлы).|
|`/tmp`|Операционная система и многие программы используют этот каталог для хранения временных файлов. Как правило, этот каталог очищается при загрузке системы и может быть удален в любое другое время без предупреждения.|
|`/usr`|Содержит исполняемые файлы, библиотеки, справочные файлы и т. д.|
|`/var`|В этой директории хранятся файлы с переменными данными, такие как файлы журналов, почтовые ящики, файлы, относящиеся к веб-приложениям, файлы cron и многое другое.|
