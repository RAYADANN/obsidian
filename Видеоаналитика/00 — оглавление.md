## Карта области

```
Сцена
  → Оптика (аберрации / асферика / iris)
  → Сенсор (CCD/CMOS) + ISP (WDR, AE)
  → Кодек (H.264/265, GOP, битрейт, FPS)
  → Декод
  → CNN (свёртки) / классика
  → Детекция → трекинг → правила
  → Событие
```

PPM на объекте задаёт потолок: 40 → 90 → 150 → 250 → 500 → 1000.
