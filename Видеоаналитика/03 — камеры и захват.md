# 03 — Камеры и захват

> Цель: понимать источник данных — без хорошего входа модель бесполезна.

---

## Типы камер (практический взгляд)

| Тип | Когда используют |
|---|---|
| IP-камера | Стандарт для видеоаналитики |
| Аналог + энкодер | Legacy-объекты |
| USB / веб | Лабы, прототипы |
| Специализированные | Тепловизор, LPR, fisheye |

Для VA почти всегда работаем с **IP + сетевой поток**.

---

## Ключевые параметры изображения

- **Разрешение** — 720p / 1080p / 4K. Больше ≠ всегда лучше для аналитики.
- **FPS** — 5–10 часто хватает для периметра; 25–30 для быстрого движения.
- **Битрейт / кодек** — H.264, H.265 (HEVC), иногда MJPEG.
- **FOV / объектив** — угол обзора, дистанция до объекта.
- **Освещение** — день/ночь, IR, WDR, backlight.
- **Монтаж** — высота, наклон, стабильность, грязь на объективе.

Правило: **сначала сцена и камера, потом модель**.

---

## Потоки

- **Main stream** — высокое качество для записи/просмотра
- **Substream** — ниже разрешение, удобен для аналитики и preview
- **ONVIF** — стандарт управления/обнаружения IP-камер
- **RTSP** — типичный протокол получения потока  
  Пример вида: `rtsp://user:pass@ip:554/Streaming/Channels/101`

---

## Что влияет на качество детекции

1. Объект слишком мелкий в кадре (мало пикселей на человека/номер)
2. Сильный motion blur
3. Пересвет / недосвет / силуэт против окна
4. Дождь, снег, конденсат, паутина
5. Качающееся крепление / вибрация
6. Сжатие (блочность, артефакты H.264)

Ориентир для людей: часто хотят **≥ 60–100 px** по высоте силуэта (зависит от задачи/модели).

---

## ROI и зоны

Ещё на этапе камеры/конфига:
- обрезать небо / стену / дорогу без интереса
- выделить вход, кассу, периметр
- не считать объекты «за стеклом напротив»

ROI снижает нагрузку и ложные срабатывания.

---

## Чеклист приёмки камеры под аналитику

- [ ] Объект интереса читаем в типичных условиях
- [ ] Есть ночной режим / IR (если нужно 24/7)
- [ ] Стабильный RTSP, известны URL main/sub
- [ ] Время на камере синхронизировано (NTP)
- [ ] Понятна геометрия: высота, угол, дистанция
- [ ] Substream подходит по FPS/разрешению под модель
