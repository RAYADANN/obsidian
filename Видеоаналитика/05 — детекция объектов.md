# 05 — Детекция объектов

> Статус: каркас — заполняем по мере изучения.

---

## Суть

Найти в кадре объекты нужных классов и отдать **bbox + class + confidence**.

---

## Что изучить

- [ ] One-stage vs two-stage детекторы
- [ ] YOLO-семейство (идея, почему популярно в VA)
- [ ] NMS и порог confidence
- [ ] mAP, IoU
- [ ] Мелкие объекты и плотность сцены
- [ ] Specialized detectors: face, plate, smoke/fire

---

## Ключевые формулы/понятия

- **IoU** — пересечение / объединение боксов
- **NMS** — убрать дублирующие боксы
- **Anchor / anchor-free** — как модель предлагает боксы
