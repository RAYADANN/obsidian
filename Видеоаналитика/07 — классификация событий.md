# 07 — Классификация событий

> Статус: каркас — заполняем по мере изучения.

---

## Суть

Превратить треки/детекты в **бизнес-события** по правилам или моделям поведения.

---

## Типовые правила VA

| Событие | Логика (упрощённо) |
|---|---|
| Intrusion | Объект класса X вошёл в полигон |
| Line crossing | Трек пересёк направленную линию |
| Loitering | Объект в зоне дольше T секунд |
| Left / removed object | Статичный объект появился/пропал |
| Crowding | Плотность / count > порога |
| Wrong direction | Движение против разрешённого вектора |
| PPE / атрибуты | Нет каски / жилета (отдельная модель) |
