# 08 — Метрики и качество

> Статус: каркас — заполняем по мере изучения.

---

## Суть

Оценивать систему так, как её видит заказчик: **ложные тревоги, пропуски, задержка, стабильность**.

---

## Метрики модели

| Метрика | Смысл |
|---|---|
| Precision | Из поднятых алертов — сколько верных |
| Recall | Из реальных событий — сколько поймали |
| F1 | Баланс precision/recall |
| mAP / IoU | Качество детекции боксов |
| FPS | Пропускная способность |
| Latency | Время до события |

---

## Метрики продукта

- False Alarm Rate (FAR) — тревог в час/сутки
- Missed events
- Uptime пайплайна
- Стоимость ложной тревоги для оператора

Часто важнее **снизить FAR**, чем выжать +1% recall.

---

## Что изучить

- [ ] Confusion matrix на событиях (не только на боксах)
- [ ] Разметка тестового набора со своего объекта
- [ ] A/B порогов confidence
