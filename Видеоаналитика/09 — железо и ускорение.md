# 09 — Железо и ускорение

> Статус: каркас — заполняем по мере изучения.

---

## Суть

Где крутить inference и декод: от камеры с SoC до сервера с GPU.

---

## Варианты

| Уровень | Примеры | Когда |
|---|---|---|
| On-camera | Камеры с встроенной аналитикой | Простые события, мало кастома |
| Edge box | Jetson, Coral, мини-ПК + GPU | Объект без толстого канала |
| Server | x86 + NVIDIA | Много камер, тяжёлые модели |
| Cloud | GPU-инстансы | Пиковые нагрузки / централизация |
