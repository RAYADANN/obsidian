# 11 — Сценарии применения

> Статус: каркас — заполняем кейсами по мере изучения.

---

## Зачем эта заметка

Одинаковые алгоритмы (детект + трек + правила) упаковываются в разные продукты. Здесь — карта сценариев и что в каждом критично.

---

## Сценарии

| Сценарий | Ключевые модули | Критично |
|---|---|---|
| Периметр / intrusion | person/vehicle + zones | FAR ночью, погода |
| People counting | detector + tracker + line | ID switch у входа |
| Очереди / occupancy | count + dwell | калибровка зон |
| LPR / ANPR | plate detect + OCR | угол, скорость, IR |
| Face (если законно) | detect + embed + gallery | privacy, освещение |
| PPE / safety | атрибуты + зона | ракурс, мелкий объект |
| Smoke / fire | спец. модели | ложные от пара/пыли |
| Ритейл shelf / heatmaps | треки + зоны | согласие/этика |
