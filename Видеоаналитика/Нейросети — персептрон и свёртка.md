# Нейросети — персептрон и свёртка

> База, на которой стоят современные детекторы. Сначала одна «нейронка», потом свёртка как способ смотреть на изображение локально.

---

## 1. Задача обучения с учителем (контекст)

Есть вход \(\mathbf{x}\) (числа: пиксели, признаки).  
Нужен выход \(y\) (класс, вероятность, координаты бокса…).

Модель — функция с параметрами (весами) \(f(\mathbf{x}; \mathbf{w})\).  
Учимся подбирать \(\mathbf{w}\), чтобы на примерах ошибка была мала.

Видеоаналитика на DL: кадр (или кусок) → сеть → «человек 0.92 в боксе (x,y,w,h)».

---

## 2. Персептрон

### 2.1. Идея

**Персептрон** (Rosenblatt, конец 1950-х) — простейшая модель нейрона / линейного классификатора:

1. Входы \(x_1, x_2, \ldots, x_n\) умножаются на веса \(w_1, \ldots, w_n\)
2. Суммируются и добавляется смещение \(b\) (bias)
3. Через функцию активации получается выход

\[
z = \sum_{i=1}^{n} w_i x_i + b = \mathbf{w}\cdot\mathbf{x} + b
\]

\[
y = \phi(z)
\]

Классический жёсткий персептрон:

\[
y =
\begin{cases}
1, & z \ge 0 \\
0, & z < 0
\end{cases}
\]

Геометрически: веса задают **гиперплоскость**, разделяющую классы. Для 2D — прямая.

```
x1 ──w1──┐
x2 ──w2──┼──► Σ ──► φ ──► y
x3 ──w3──┘      ↑
                b
```

### 2.2. Чему «учится»

Правило обновления весов (упрощённо): если ошибся на примере — подвинуть \(\mathbf{w}\) так, чтобы в следующий раз ответ был ближе к правильному.

Ограничение: **линейно разделимые** задачи. XOR одним персептроном не решить → нужны **многослойные** сети (MLP).

### 2.3. Современный взгляд

Один нейрон в MLP:

- линейное преобразование \(\mathbf{w}\cdot\mathbf{x}+b\)
- нелинейность: ReLU, sigmoid, tanh…

Слой = много таких нейронов рядом.  
Глубокая сеть = много слоёв.  
Персептрон — **атом**, из которого собирают большие модели (наряду со свёртками, attention и т.д.).

### 2.4. Зачем это видеоаналитику

Понимать:

- сеть — это не «магия», а настраиваемая функция;
- без нелинейностей много слоёв схлопываются в одну линейную;
- переобучение, данные, разметка — следствие той же схемы обучения.

## 3. Свёрточная функция (convolution) в CV

### 3.1. Зачем не подавать все пиксели в обычный MLP сразу

Картинка 1920×1080×3 ≈ 6 млн входов. Полносвязный слой на все пиксели:

- гигантское число весов;
- нет учёта того, что **соседние пиксели связаны**;
- сдвиг объекта на 5 px ломает все веса.

Нужен оператор, который:

- смотрит **локально** (маленькое окно);
- **одинаков в разных местах** кадра (один детектор края и слева, и справа);
- уменьшает/укрупняет представление иерархически.

Это и есть **свёртка**.

### 3.2. Свёртка на изображении — буквально

Есть ядро (фильтр, kernel) — маленькая матрица весов, например 3×3:

```
K = [ k11 k12 k13 ]
    [ k21 k22 k23 ]
    [ k31 k32 k33 ]
```

Накладываем на кусок изображения, **поэлементно умножаем и суммируем** → одно число на выходе (отклик в этой точке).  
Сдвигаем окно дальше (stride) — получаем **карту признаков (feature map)**.

\[
(I * K)(x,y) = \sum_{i}\sum_{j} I(x+i, y+j)\cdot K(i,j) + b
\]

(в DL часто technically cross-correlation — ядро не переворачивают; на результат обучения это не принципиально).

### 3.3. Интуиция фильтров

Ручные примеры (до DL так делали в OpenCV):

| Ядро | Эффект |
|---|---|
| Сглаживание (гаусс) | Blur, меньше шума |
| Sobel / Scharr | Границы (edges) |
| Laplacian | Вторые производные, контуры |
| Identity | Почти исходник |

В CNN веса ядра **не задают вручную** — их **обучают**: первые слои часто сами становятся детекторами краёв/текстур, глубже — частей объектов, ещё глубже — объектов.

### 3.4. Важные гиперпараметры свёртки

| Параметр | Смысл |
|---|---|
| Kernel size | 1×1, 3×3, 5×5… — поле зрения одного отклика |
| Stride | Шаг сдвига; >1 уменьшает карту |
| Padding | Рамка нулей/отражения, чтобы размер не схлопнулся |
| Channels / filters | Сколько разных ядер → сколько feature maps |
| Dilation | «Дырявое» ядро — больший receptive field без роста параметров |

После свёртки обычно:

- **активация** (ReLU…)
- иногда **pooling** (max/avg) — уплотнение, лёгкая инвариантность к сдвигу
- нормализация (BatchNorm…)

### 3.5. Свёрточная нейросеть (CNN) — стопка

```
Кадр
  → Conv + ReLU   (низкоуровневые признаки)
  → Conv + pool
  → Conv …        (всё более абстрактно)
  → Head:
       • классификация (что в кадре)
       • детекция (боксы) — YOLO, SSD, Faster R-CNN…
       • сегментация (маска на пиксель)
```

**Receptive field** — область исходного кадра, влияющая на один выход глубокого нейрона. Чем глубже/больше stride — тем шире контекст.

### 3.6. Свёртка vs персептрон — сравнение

| | Персептрон / Dense | Свёртка |
|---|---|---|
| Связность | Каждый вход с каждым (в слое) | Локальная |
| Веса | Свои на каждую связь | **Разделяемые** по пространству |
| Индуктивный bias | Мало «знает» про картинку | Соседство + сдвиговая одинаковость |
| Параметры на HD | Взрываются | Управляемы |
| Применение | Табличные признаки, головы сетей | Ствол CV-моделей |

В детекторе: **свёрточный backbone** + головки, где уже могут быть и свёртки, и полносвязные куски.

## 4. От кадра к событию (мост к аналитике)

```
Пиксели
  → CNN-признаки
  → Детекции (класс, confidence, bbox)
  → Трекинг (ID во времени)
  → Правила / вторая модель
  → Событие VA
```

Персептрон объясняет «как нейрон принимает решение».  
Свёртка объясняет «как смотреть на изображение эффективно».

## 5. Мини-упражнения для закрепления

1. Нарисовать персептрон с 2 входами; подобрать веса для AND (порог).
2. Взять ядро Sobel 3×3 и вручную посчитать отклик на куске 3×3 из 0/1.
3. Объяснить своими словами, почему один и тот же фильтр края применяют по всему кадру.

---

## Резюме

- **Персептрон** — взвешенная сумма входов + порог/активация; линейный классификатор; кирпичик сетей.
- **Свёртка** — скользящее локальное скалярное произведение ядра с изображением; основа CNN.
- Современная VA на DL почти всегда = свёрточные (или гибридные) сети + постпроцессинг.
