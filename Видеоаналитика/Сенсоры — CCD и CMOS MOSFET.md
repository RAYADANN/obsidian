# Сенсоры — CCD и CMOS (MOSFET)

> Как матрица превращает свет в электрический сигнал. CCD и CMOS — два разных пути; в CMOS в каждом пикселе работает MOSFET.

---

## 1. Общая идея сенсора

Фотон попал на фоточувствительный элемент → сгенерирован заряд / ток → считан → оцифрован АЦП → пиксельное значение яркости (и цвета через фильтр Байера).

```
Свет → Фотодиод (электронно-дырочные пары)
     → Накопление заряда за время экспозиции
     → Считывание
     → Усиление
     → АЦП
     → Цифровой кадр
```

Два классических семейства: **CCD** и **CMOS**.

---

## 2. CCD (Charge-Coupled Device)

### 2.1. Принцип

1. В каждом пикселе за время экспозиции накапливается **пакет заряда** (пропорционален свету).
2. Заряды **сдвигаются** по столбцам/строкам как «конвейер» (charge coupling) к одному или нескольким выходным усилителям.
3. На выходе заряд → напряжение → АЦП (часто вне чипа в старых системах).

Аналогия: все ведёрки с водой передают содержимое по цепочке к одному крану, где измеряют объём.

### 2.2. Свойства (исторически сильные)

| Плюс | Минус |
|---|---|
| Высокая однородность (один выходной путь) | Медленнее считывание при большом разрешении |
| Хороший квантовый выход / низкий шум (в качественных CCD) | Выше энергопотребление |
| Мало «электронного» шума считывания на пиксель | Blooming: пересвет «течёт» в соседние ячейки |
| | Дороже, сложнее интеграция с логикой на том же кристалле |
| | Слабее живут в массовом IP-рынке сегодня |

### 2.3. Где ещё встречаются

Станки, наука, старые аналоговые/ранние цифровые камеры. В современном CCTV/IP почти везде **CMOS**.

---

## 3. CMOS и MOSFET

### 3.1. Что такое CMOS-сенсор

**CMOS** (Complementary Metal-Oxide-Semiconductor) — технология изготовления чипов, где логика строится на парах транзисторов.

В **CMOS image sensor** у **каждого пикселя** (или у группы) есть своя **схема считывания на транзисторах**. Ключевой элемент — **MOSFET** (Metal-Oxide-Semiconductor Field-Effect Transistor): полевой транзистор, которым управляют затвором через оксидную изоляцию.

Типичный активный пиксель (APS — Active Pixel Sensor):

```
Фотодиод
   │
   ▼
Reset MOSFET  — сброс пикселя перед экспозицией
Transfer / select MOSFET — выбор строки/пикселя
Source follower MOSFET — буфер (усилитель) сигнала
   │
   ▼
Колоночная шина → усиление → АЦП (часто на кристалле)
```

Именно это имеют в виду, когда говорят «CCD vs MOSFET»: не «CCD против одного транзистора», а **CCD (перенос заряда) vs CMOS-пиксель на MOSFET-схеме**.

### 3.2. Почему CMOS победил в IP-камерах

| Плюс CMOS | Комментарий |
|---|---|
| Считывание параллельное / построчное | Высокий FPS, 4K реально |
| АЦП и логика на одном чипе | Дешевле система, меньше шума тракта |
| Низкое энергопотребление | Важно для PoE-камер |
| On-chip HDR, binning, ROI | Гибкость под VA |
| Массовое производство | Цена |

Минусы (частично сглажены поколениями):

- Раньше — выше fixed-pattern noise, хуже однородность
- Rolling shutter (электронный «шторный» затвор): при быстром движении — «желе», наклон вертикалей
- Global shutter CMOS дороже; в security чаще rolling

### 3.3. Rolling vs Global shutter (важно для аналитики)

| | Rolling | Global |
|---|---|---|
| Как | Строки экспонируются/читаются последовательно | Весь кадр одновременно |
| Артефакт | Wobble, partial exposure вспышек | Почти нет геометрических артефактов движения |
| VA | Быстрые авто/люди могут искажаться | Лучше для LPR, спорта, конвейеров |

## 4. Цвет: фильтр Байера

Над монохромной матрицей — мозаика цветных фильтров (обычно RGGB).  
Каждый пиксель «видит» один цвет → **демозаика** восстанавливает RGB.

Следствия:

- Реальное цветовое разрешение ниже номинальных мегапикселей
- На тонких контрастных краях — цветной шум / zipper
- Для LPR/лиц важна резкость яркости (luma), не «маркетинговый» цвет

Монохромные матрицы без Байера резче — иногда в спецкамерах.

---

## 5. Шум и чувствительность (связь с ДД)

Источники шума:

- **Фотонный (shot) noise** — статистика самого света
- **Dark current** — тепловая генерация заряда
- **Read noise** — шум считывания/АЦП
- **Gain noise** — при усилении ISO/gain

При малом свете камера поднимает **gain** → шум → аналитика видит «снег» и ложные контуры.  
Поэтому ночью важны: светосила объектива, размер пикселя, режим IR, разумный порог gain, а не только «больше Мп».

Крупный пиксель (меньшая плотность на том же размере матрицы) обычно лучше ловит свет — компромисс с разрешением.

---

## 6. Размер матрицы и объектив

Форматы: 1/2.8", 1/1.8", 1/1.2" и т.д. (диагональ примерно).

- Меньшая матрица → дешевле, нужен другой объектив под тот же угол
- «Мегапиксели» без указания размера матрицы и объектива ничего не говорят о PPM на объекте

## 7. Сравнительная таблица для запоминания

| | CCD | CMOS (MOSFET pixel) |
|---|---|---|
| Считывание | Сдвиг зарядов к общему выходу | Транзисторы в пикселе / колонке |
| Скорость | Ниже на больших разрешениях | Высокая |
| Энергия | Выше | Ниже |
| Интеграция | Слабее | SoC + ISP рядом |
| Blooming | Характерен | Меньше / другой характер |
| Рынок CCTV 2020-е | Нишевый | Доминирует |

## 8. ISP — невидимый этап

Между сырой матрицей и H.264 почти всегда стоит **ISP** (Image Signal Processor):

- demosaic, denoise, sharpen
- автоэкспозиция (AE), автобаланс белого (AWB)
- WDR/HDR склейка
- gamma / tone mapping

Для аналитики агрессивный sharpen/denoise может **рисовать артефакты** или убивать текстуру. На тестовых стендах иногда сравнивают режимы ISP.

---

## Резюме

- **CCD** — заряд бежит конвейером к одному усилителю.
- **CMOS** — в пикселе работают **MOSFET**-ключи и буфер; параллельное чтение.
- В IP-видеоаналитике почти всегда CMOS + ISP + кодек.
- Качество ночи и ДД определяется физикой пикселя + объективом + настройками gain/shutter не меньше, чем нейросетью.
