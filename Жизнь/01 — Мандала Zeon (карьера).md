## 8 опор (внутренний квадрат)

| Опора | Зачем именно тебе |
|-------|-------------------|
| **Выпуск** | Без soft launch нет ответа «почему не зашло». Код без игроков = ноль. |
| **Продукт** | Силён в архитектуре; слабое место — retention и «зачем возвращаться». |
| **Фокус** | Несколько проектов сразу = распыление. Одна ставка на квартал. |
| **Крафт** | UI/VFX — топливо и отличие. Без лимита прячется от выпуска. |
| **Рынок** | Ответ дают игроки и деньги, не Obsidian. |
| **Деньги** | Без денег мотивация гаснет — runway часть цели. |
| **Тело и ум** | Рутина снимает стресс, сила идёт в игру. |
| **Система** | Starter/rules — суперсила. Рычаг, не убежище от риска. |

## 64 действия

### Выпуск
1. Один вертикальный срез ≤ 15 мин петли
2. Дата soft launch до старта кода
3. Всё вне среза → BACKLOG, не в спринт
4. Playtest на 10–20 людях до «полировки»
5. Definition of Done = играбельно, не «красиво»
6. После релиза: 7 дней только метрики + hotfix
7. Запрет новых систем в неделю до launch
8. Постмортем на 1 страницу после каждого релиза

### Продукт
1. Перед кодом: 1 хук возвращения
2. Новичок понимает цель за 30 сек
3. Одна core loop, не «история на один раз»
4. Монетизация вшита в loop
5. Сравнить идею с 3 живыми хитами жанра
6. Kill-критерий идеи до старта
7. 2 часа/неделя играть топ Roblox (не смотреть)
8. Записывать: что удержало 20+ мин

### Фокус
1. Один активный игровой проект на квартал
2. Остальное — архив или BACKLOG с датой
3. Утро: 1 главная задача на день
4. Инструменты (VFX/plugin) только после revenue
5. Не стартовать «машину идей» вместо релиза
6. Макс. 2 исследовательских сессии / неделя
7. Закрывать Cursor, если нет DoD на сегодня
8. Раз в неделю: выкинуть 1 отвлечение

### Крафт
1. Juice только на 1–2 signature момента
2. Телефон — главный viewport
3. Тема + UI-правила — не изобретать заново
4. Полировка после playtest, не до
5. 1 час крафта/день max до soft launch
6. Сравнивать feel с эталоном жанра, не с Unreal
7. Фиксировать «вау» в starter
8. Крафт без метрики = хобби, не работа студии

### Рынок
1. Analytics с первого дня
2. Ads/органика — эксперимент с гипотезой и потолком бюджета
3. План первых игроков до публикации
4. График обновлений 1.1 / 1.2
5. Конкуренты: loop + monetization, не скины
6. Не путать исследование с прогрессом
7. 1 внешний фидбек / неделя (игрок, не AI)
8. Pivot только по цифрам

### Деньги
1. Личный минимум / месяц — число на бумаге
2. ProductIds реальные до launch
3. Путь к первой оплате ≤ 60 сек
4. Не строить «студию мечты» без cashflow
5. 1 день/мес на портфолио/офер (backup)
6. Грубо считать CAC vs LTV после ads
7. Инфра (4090 / локальный AI) — только из прибыли
8. Первая тысяча Robux — milestone

### Тело и ум
1. Сон в одно окно ±30 мин
2. Deep work 3–4 ч без чатов/Reels
3. Движение 30 мин / день
4. Еда до deep work
5. Лимит соцсетей: слот, не скролл
6. Вечер: закрытие дня 10 мин
7. Один полный выходной без «чуть поправить»
8. Тревогу «провал» → план на завтра

### Система
1. Один живой статус (не 6 летописей)
2. Баг в логике → сначала тест, потом фикс
3. Правила Cursor — только после реального урока
4. Постмортем → 1 правило или 0
5. Знания вокруг shipped игр, не теорий
6. Агенты/анализ — только с вопросом и дедлайном
7. Не искать «машину предсказания хита» до 3 релизов
8. Система служит релизу; релиз не служит системе

## 7 правил (карьерный контур)

1. Сначала выпустить, потом расширять
2. Один активный игровой проект
3. Истина — игроки и метрики
4. Крафт после доказанной петли
5. Деньги — часть цели
6. Системы только из уроков релиза
7. Спросить правду, не лесть
