## 1. Центр (1–3 года)

**Финансовая независимость = свобода выбора.**

Расшифровка из твоих слов:
- Выбор, а не заложник работы / чужой идеи / «нет денег на свидание».
- Родители не надрываются ради экономии.
- Своя жизнь: жильё, машина (ориентир Voyah Free), студия, человек рядом.
- Через ~3 года: студия ~700к+/мес, команда, проекты; ты — человек слова, на которого можно положиться.
- Признание снаружи **и** перед собой: «я тот, кем хотел быть».

**Главный рычаг на этот год (измеримо):**  
игра Zeon попадает в **Top Roblox** (или доказуемо близко: устойчивый CCU / retention / выручка — зафиксируешь цифру после первого soft launch).

Roblox — не конечная мечта, а **выбранный путь к свободе** (опыт + системы + нравится строить). Путь можно сменить; свобода — нет.

## 2. Что для тебя правда (сжатый портрет)

| Тянет | Режет |
|-------|--------|
| Деньги → свобода → выбор | Чувство «отстающий в 25» (топливо, но и давление сравнения) |
| Своё дело, системы, довести до конца | Официальная работа + 2 ч дороги едят вечер |
| Девушка / друзья как давление и поддержка | Instagram / Reels в дороге и в «скуке» |
| День «всё успел» (работа → Roblox → учёба → люди) | «Отдых» = ничегонеделание или скролл, пока Cursor пишет |
| Слово, надёжность, влияние | Нет порога «достаточно на сегодня» — стоп только когда голова пустая |
| Зал 2×/неделя, спортсменское прошлое | Еда/энергия недонастроены; спокойствие в конце рейтинга |

**Главный конфликт:** хочешь одержимости делом, но сам пишешь, что одной работы мало — без людей/жизни снесёт в выгорание. Значит одержимость = **жёсткий блок на Zeon каждый день**, а не «вырезать всю жизнь».

## 3. Ценности (твой порядок) → как жить

1. **Деньги / безопасность** → каждый день шаг к выручке с игр, не только «знания».  
2. **Свобода** → решения, которые уменьшают зависимость от чужой идеи и чужого жилья.  
3. **Влияние / след** → Top + студия, не бесконечная подготовка.  
4. **Отношения** → девушка, друзья, наставник Roblox — сознательно в расписании, не «если останется время».  
5. **Признание** → через релизы и слово, не через сравнение с окружением в голове.  
6. **Здоровье** → еда + зал как топливо свободы (не «потом»).  
7. **Мастерство** → обучение *в* проекте и после релиза, не вместо релиза.  
8. **Спокойствие** — низкий приоритет ок; но без минимального восстановления дисциплина ломается.

## 4. Опоры жизни (7)

Не квадрат — семь опор, без которых центр рушится.

### 1. Деньги → свобода
- Личный ориентир: **250к+/мес** (не думать о выживании + рост).  
- Сейчас: работа ~90–100к; остальное — цель с Roblox.  
- Пока работа нужна — не враг, а runway. Параллельно — путь к замене.

### 2. Zeon / выпуск
- Год не зря = **хотя бы одна игра в Top** (или явный трафик/деньги до Top).  
- Не делать всё, что не деньги / не цель / не удовольствие.  
- Правило №1 (твоё): **каждый день** — вклад в текущий проект **и** знание по Roblox под востребованные игры.

### 3. Дисциплина дня
- Фиксированный блок Zeon после работы (даже короткий).  
- Не ждать «одержимости» как чувства — ставить слот.  
- DoD дня ≠ «мозг выключился», а **закрыт слот + 1 конкретный результат** (шипнули / потестили / выучили X / метрика).

### 4. Отношения (топливо, не утечка)
- Ближе: амбициозные люди (особенно Roblox), девушка «своя», друзья.  
- Искать: наставник Roblox, поддержка, романтика.  
- Вечер с людьми — по плану 2–3 ч, не вместо слота Zeon и не бесконечный чат вместо отдыха.

### 5. Тело
- Зал ≥2×/неделя — оставить.  
- Уплотнить завтрак, подкрутить обед → энергия и масса.  
- Сон 7–8 ч — не трогать.

### 6. Среда
- Цель года: **съехать от друга**, своё жильё (аренда ок).  
- Зоны: работа / отдых. Без зоны «офис» выходные размываются в Reels и болтовню.

### 7. Характер
- Усилить: человек слова; доводить до конца (Roblox — полигон).  
- «Доминирование» в твоём смысле = **не быть финансово зависимым и не чувствовать себя младшим в комнате** → достигается результатами и выбором, не позой.  
- Убить: лень / дыры в дисциплине; сравнение с более успешными друзьями → перевод в план на неделю, не в злость без действия.

## 5. Правила жизни (рабочие)

1. **Каждый день — слот Zeon + одно знание под хит** (твоё правило №1).  
2. **Сначала выпустить, потом расширять** (уже в starter).  
3. **Один активный игровой проект.**  
4. **Instagram/Reels не заполняют дорогу и «скуку» на работе** — заранее: подкаст / заметки / чтение по Roblox / отдых глазами.  
5. **Люди в календаре, не вместо календаря.**  
6. **День закончен, когда закрыт DoD**, не когда сил ноль.  
7. **Инвестор и найм — только после первого успешного проекта** (ты сам так сказал).  
8. **Слово = сделал.** Маленькие обещания себе считаютcя.

## 6. Добавить / вычеркнуть

### Добавить (из «дисциплина / одержимость / страсть» → действия)
1. **Ежедневный слот Zeon** (минимум 60–90 мин в будни; больше в дни без срыва).  
2. **Еженедельный playtest / метрика / решение** — страсть к *результату*, не к процессу.  
3. **Поиск наставника / круга Roblox** (1 касание в неделю: Discord, dev, чат).  
4. **Ритуал еды** (завтрак плотнее).  
5. **План переезда** (срок + бюджет) — среда под свободу.  
6. **Осознанный отдых** 1 слот/неделя (прогулка, зал, люди) — без Reels-заглушки.

### Вычеркнуть / заморозить
1. **Instagram Reels** как фон жизни (лимит или удаление на 90 дней).  
2. **«Курсор пишет — я в ленте»** — либо смотришь прогресс / тестишь, либо отдыхаешь иначе.  
3. **Всё, что не деньги / не цель / не удовольствие** (твоя формулировка) — в BACKLOG.  
4. **Параллельные «машины идей», плагины, AI-фермы** до первого сильного релиза.  
5. **Сравнение с окружением без плана** — 5 мин злости → 1 действие в Zeon.

## 9. 90 дней — старт (не вся жизнь сразу)

1. Правило №1 каждый день (трекер: да/нет).  
2. Instagram: удалить или лимит 15 мин/день, не в дороге.  
3. DoD дня = слот закрыт + 1 артефакт (билд / тест / заметка знания).  
4. Один проект → дата soft launch.  
5. Раз в неделю: 1 сообщение в сторону наставника/круга.  
6. Набросок бюджета переезда.

Через 90 дней — пересмотреть только якоря и cut-list, не всю философию.
