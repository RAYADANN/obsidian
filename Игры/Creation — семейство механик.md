# Creation — семейство механик

> Часть: [[Механики удержания — обзор]]

«Создание» в играх — зонтичный термин. Разложение на **8 подтипов**.

---

## Схема семейства

```
                    ┌─────────────────────────────────┐
                    │         CREATION FAMILY          │
                    └─────────────────────────────────┘
                                      │
        ┌──────────┬──────────┬───────┴───────┬──────────┬──────────┐
        ▼          ▼          ▼               ▼          ▼          ▼
   Construction  Cultivation Transformation  Layout   Customization Collection-as-Creation
        │          │          │               │          │          │
        └──────────┴──────────┴───────┬───────┴──────────┴──────────┘
                                      ▼
                              Optimization + Expression
```

---

## 1. Construction (строительство)

**Суть:** собрать объект из частей в пространстве.

| | |
|---|---|
| **Примеры** | Minecraft, Bloxburg, Theme Park Tycoon, Build A Boat |
| **Крючок** | spatial puzzle + «я это сделал руками» |

---

## 2. Cultivation (культивация)

**Суть:** посадил → ухаживал → выросло → пожал.

| | |
|---|---|
| **Примеры** | Grow a Garden, Hay Day, Pet simulators (выращивание питомца) |
| **Крючок** | nurturing + ожидание с наградой + «живой» объект |

**Отличие от construction:** результат **растёт во времени**, а не появляется мгновенно.

→ [[Grow a Garden — разбор]]

---

## 3. Transformation (трансформация мира)

**Суть:** изменить состояние среды — выкопал блок, срубил дерево, открыл проход.

| | |
|---|---|
| **Примеры** | Minecraft mining, Deep Digger, Deep Signal |
| **Крючок** | agency через разрушение/изменение — мир *помнит* твоё действие |

Каждый удар по блоку — **микро-создание пустоты** и **открытие глубины**.

→ [[Mining и Deep Signal — применение]]

---

## 4. Layout / Planning (планировка)

**Суть:** организовать систему — где что стоит, как течёт ресурс.

| | |
|---|---|
| **Примеры** | Factory games, tycoon layouts, оптимизация сада в Grow a Garden |
| **Крючок** | puzzle + efficiency |

---

## 5. Customization (персонализация)

**Суть:** изменить *себя* или *интерфейс владения*, не обязательно физический мир.

| | |
|---|---|
| **Примеры** | Adopt Me (дом + аватар), Brookhaven (одежда, машина) |
| **Крючок** | identity + social signaling |

---

## 6. Collection-as-Creation (коллекция как «создание себя»)

**Суть:** «я собираю сет» = «я создаю свою коллекцию / музей / инвентарь».

| | |
|---|---|
| **Примеры** | Pet Simulator (полный альбом), 50 руд, журнал Эхо в Deep Signal |
| **Крючок** | completionism + display |

---

## 7. Optimization (создание эффективной системы)

**Суть:** игрок «создаёт» не объект, а **машину прогресса**.

| | |
|---|---|
| **Примеры** | rebirth builds, pet loadouts, mutation stacking в Grow a Garden |
| **Крючок** | mastery для «умных» игроков; контент для стримеров/гайдов |

---

## 8. Expression (самовыражение)

**Суть:** эстетика, стиль, «мой уникальный look».

| | |
|---|---|
| **Примеры** | декор сада, скины, showcase builds |
| **Крючок** | social validation + TikTok/YouTube clips |

---

## Как выбирать sub-type при дизайне

1. **Какой sub-type creation?** (build / grow / dig / customize / collect)
2. **Что игрок «владеет»?** (plot, pet, depth record, journal)
3. **Виден ли прогресс глазами?** (не только HUD)
4. **Есть ли offline / daily hook?**
5. **Есть ли social story?** (что игрок расскажет другу)

**Правило:** выбери **один** sub-type и доведи до конца. Не «и сад, и стройка, и крафт» одновременно на MVP.
