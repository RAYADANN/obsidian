# Minecraft vs Roblox — creation

> Часть: [[Механики удержания — обзор]]

Разная философия «создания» в двух платформах.

---

## Сравнительная таблица

| | Minecraft | Типичный Roblox hit |
|---|---|---|
| **Глубина creation** | Очень высокая (voxels, redstone) | Средняя (prefabs, slots, plots) |
| **Барьер входа** | Выше (нужно учиться) | Ниже (один клик = результат) |
| **Session length** | Часы (deep play) | 5–20 мин (loop sessions) |
| **Монетизация creation** | Skins, Realms | Gamepasses, boosts, eggs |
| **Social** | Серверы, showcase builds | In-game flex, TikTok clips |
| **Тип creation** | Free-form | Guided (в рамках) |

## Minecraft — почему культовый

Не одна механика, а **стек**:

| Столп | Роль |
|---|---|
| [[Creation — семейство механик#Construction\|Construction]] | Постройка чего угодно |
| [[Creation — семейство механик#Transformation\|Transformation]] | Копание, изменение ландшафта |
| Exploration | Биомы, пещеры, «что за углом» |
| Progression | Дерево крафта, tiers инструментов |
| Survival (light) | Ночь, мобы — лёгкий риск |
| Collection | Редкие блоки, ресурсы |
| Social | Показать постройку, совместное строительство |

**Freedom of choice + visible world change** = core fantasy.

---

## Roblox — guided creation

Roblox creation почти всегда **guided creation**:
- не «сделай что угодно»
- а «сделай красиво *внутри рамок*» (plot, slots, prefabs)

**Trade-off:**
- ✅ меньше freedom → больше dopamine/minute
- ✅ ниже барьер → шире аудитория
- ❌ меньше «настоящего» builder-контента
- ❌ сложнее конкурировать с Minecraft на его поле

## Implication для нашего проекта

Deep Digger / Deep Signal — **не конкурирует с Minecraft** на building.

Наш creation sub-type = **Transformation** (копание = изменение мира).

Сильные стороны vs Roblox simulators:
- spatial progress (глубина видна)
- exploration (новые слои)
- unique tension layer (Deep Signal)
