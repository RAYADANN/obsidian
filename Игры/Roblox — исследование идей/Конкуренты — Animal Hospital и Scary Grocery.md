## Animal Hospital (Anomaly) 🧪

**Студия:** Animal Anomaly  
**Релиз:** 10 May 2026  
**Формула:** night shift + co-op + «real vs anomaly patient»

### Метрики (июль 2026, агрегаторы)

| Метрика | Значение |
|---|---|
| Peak CCU | **~1.27M** (Rolimons) |
| Visits | **700M+** |
| Rating | ~95%+ positive |
| Max players | 30 |

### Почему взлетело

- Понятный hook за 5 сек: «работаешь в клинике, часть пациентов — не те»
- Co-op до 30 игроков
- Readable mechanics (check-in, rooms, tools)
- Live updates + новые anomaly types
- **Не продаёт сюжет** — продаёт shifts, classes, collection

### Монетизация (ориентир)

- In-game **Animal Coins** за shifts → классы/апгрейды
- Robux-классы: Head Nurse (140 R$), Secret Agent (790 R$ + gun)
- Optional passes ~50–500 R$ — convenience/cosmetic, не required to win

### Что взять для своей игры

- Shift-based loop (не story chapters)
- Anomaly catalog / collection
- Co-op roles с разным информационным доступом
- Weekly new anomaly type = live ops

## Scary Grocery: The Night Shift [HORROR]

**Студия:** Moo Milk Studio  
**Релиз:** 22 Nov 2025  
**Формула:** grocery night shift + doppelganger detection + shooter + entity

### Метрики

| Метрика | Значение |
|---|---|
| Peak CCU | **~13.2k** |
| Visits | **~76M** |
| 24h peak (recent) | ~7.7k |
| Avg playtime | ~13 min |

### Core loop

- Scan customers at register
- Check info screen (name, age, job, location)
- Real → checkout ✅ / Doppelganger → shoot 🔫
- Restock, mop, body disposal
- Fail quota → entity
- Survive nights (badges up to night 70+)

### Монетизация (3 game passes)

| Pass | Price | Эффект |
|---|---:|---|
| 2x Customer Speed | 99 R$ | faster loop |
| Golden Shotgun | 149 R$ | combat |
| Doppelganger Scanner | **899 R$** | detect anomalies (strong P2W feel) |

**Developer products:** не prominent в публичных листингах — упор на passes + badges.

### Прямое пересечение с Shelf Shift

| Элемент | Scary Grocery | Shelf Shift (магазин) |
|---|---|---|
| Setting | Grocery | Supermarket |
| Night shift | ✅ | ✅ |
| Anomalies | Doppelgangers | Environmental + co-op |
| Co-op roles | Weak | **Core** (cashier + backroom) |
| Combat | Gun | **No gun** (prefer) |
| Day/night | No clear day loop | **Day earn / Night risk** |

→ **Scary Grocery — главный blocker** для supermarket-версии.
