# Сервисы для исследования ниш Roblox

> Часть: [[00 — оглавление]]

---

## Off-platform

| Сервис | Зачем |
|---|---|
| **YouTube Search** | demand signals — какие loops набирают просмотры |
| **Steam** | wishlists, tags, reviews, upcoming hits |
| **TikTok** | быстрый сигнал для teen audience |
| **Twitch / клипы** | «смотребельность» механики |
| **Reddit / Discord** | боль аудитории, что «не хватает» |
| **Google Trends** | грубый тренд терминов |
| **App stores** | mobile sims часто коррелируют с Roblox аудиторией |
| **CrazyGames** | browser games + attached gameplay views |

---

## On-platform (Roblox)

| Сервис | Зачем |
|---|---|
| **Roblox Discover / Search** | ручная проверка выдачи по ключам |
| **Страницы игр** | CCU proxy (likes, visits, updates, monetization) |
| **Creator Hub / Ads Manager** | цена трафика (косвенно — «дорогая» ниша) |

---

## Агрегаторы статистики

| Сервис | Что даёт |
|---|---|
| [Rolimons](https://www.rolimons.com) | peak CCU, game passes, badges |
| [RobloxGo](https://www.robloxgo.com) | visits, current players, genre |
| [Robipedia](https://robipedia.com) | passes, rating, active players |
| [CCUCheck](https://ccucheck.com) | top games, trends (частично paywalled) |
| [Bloxodes](https://bloxodes.com) | rank history, genre charts |

---

## Практичный микс (лучший signal/noise)

1. **YouTube/TikTok** — есть ли массовый интерес к loop
2. **Roblox Search + Rolimons** — перенасыщение / доминаторы
3. **Steam** — долгий тренд / платёжеспособный интерес

---

## Ограничения

- CCU агрегаторы **не синхронны** — цифры могут отличаться на 10–30%
- «Customs» / «Night Shift» — **шумные ключи**, нужны точные запросы
- Signal жанра ≠ signal **твоей** игры до launch
