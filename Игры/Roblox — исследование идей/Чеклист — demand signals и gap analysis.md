## Быстрый скрининг одной фантазии (5–10 мин)

### Off-platform (demand)

| Сервис | Что смотреть | Зелёный флаг | Красный флаг |
|---|---|---|---|
| **YouTube** | gameplay + ключ фантазии | стабильные ролики 100k–M+ views | только 1–2 старых видео |
| **Steam** | похожие sim/action | wishlists, reviews, «Popular Upcoming» | нет аналогов вообще |
| **TikTok** | хештеги лупа | залипательный loop для teens | нет контента |
| **Google Trends** | термины растут | uptrend | flat/decline |

### On-platform (gap / saturation)

| Сервис | Что смотреть | Зелёный флаг | Красный флаг |
|---|---|---|---|
| **Roblox Search** | топ-10 по ключу | мало доминаторов / однотипный RP | 5+ сильных клонов |
| **Rolimons** | peak CCU якорных игр | 1–2 средних, нет мега-хита | гигант 10k+ CCU в нише |
| **RobloxGo / Robipedia** | текущий CCU, visits | растущие новые тайтлы | всё stale |

## Формула вердикта

```
ОКНО = off-platform interest + on-platform НЕ перегрето + жанровый поворот (+20%)
ПЕРЕГРЕТО = много доминаторов + сложно отличиться в превью
НИША = стабильно, но не viral (trains, dispatch)
```

---

## Критерии «окно / перегрето» (из нашего скрининга)

**Окно:**
- off-platform интерес есть
- на Roblox мало доминаторов **или** доминирует другой поджанр (RP vs mission/extraction)
- можно зайти с трендовым жанром (extraction, checkpoint, co-op chaos)

**Перегрето:**
- много близких клонов
- 1+ сильный доминатор с высоким CCU
- сложно сделать заметно лучше без большой команды
