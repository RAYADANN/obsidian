## TL;DR

| Вопрос | Ответ |
|---|---|
| Есть ли «формула fun»? | **Нет.** Есть 3 модели: backlog→prototype, acquire→scale, genre gap+distribution |
| Главный принцип | Идея не «хорошая», пока **игроки не показали signal** (CCU, D1/D7, clips) |
| Платформа изменилась? | **Да** — RFY смотрит **28 дней**, убивает clickbait, Top-20 обновляется быстрее |
| «Сильные» игры в топе = качественные? | **Не всегда** — strong = retention + distribution + live ops |
| История как core? | **Плохой retention engine** — one-and-done; нужны collection, FOMO, co-op, prestige |
| Что избегать в 2026? | Pure brainrot escape clone (−78% CCU у лидера формата), «ещё один sim» без twist |
