## 1. Shelf Shift ⭐ (recommended)

**Genre:** Horror / Anomaly Job (Animal Hospital adjacency)

| | |
|---|---|
| Loop | Night shift supermarket — restock, scan anomalies, survive |
| Replay | Random anomalies, shift escalation, collection codex |
| Social | 2–4 co-op, split roles (scanner / restocker / guard) |
| Clip | «Don't put that on shelf 7» panic moments |
| Gap | Grocery horror exists but co-op job sim underserved |
| MVP | 1 store, 5 anomalies, 3 nights, basic codex |

**Monetization:** → [[Roblox — исследование идей/Shelf Shift — монетизация]]  
**Competitors:** → [[Roblox — исследование идей/Конкуренты — Animal Hospital и Scary Grocery]]

## 2. Rate My Base

**Genre:** Town/City + UGC competition

| | |
|---|---|
| Loop | Build base → publish → lobby votes → rank rewards |
| Replay | Weekly themes, leaderboard seasons, steal ideas meta |
| Social | Visit + vote + friend rivalry |
| Gap | Town/City +65% growth, Brookhaven ≠ competitive build |
| MVP | 1 plot, vote UI, weekly theme rotation |

**Risk:** moderation UGC, needs critical mass for votes.

---

## 3. Vertical Layer Fishing

**Genre:** Simulator (Fish It adjacency)

| | |
|---|---|
| Loop | Fish by **depth layer**, not surface spot — unlock deeper biomes |
| Replay | Collection per layer, rare depth events, prestige reset |
| Social | Show off deepest catch, co-fish bonus |
| Gap | Fish It only top-8 with +CCU — twist not clone |
| MVP | 3 layers, 10 fish, simple rod upgrade |

**Avoid:** surface fishing clone, idle-only.

---

## 4. Brainrot Brawl

**Genre:** Brainrot skin + Fighting

| | |
|---|---|
| Loop | 1v1 / FFA, simple moveset, brainrot characters |
| Replay | Unlock roster, ranked seasons, clip moments |
| Social | Duels, spectate, steal emote taunts |
| Gap | Market Friday: brainrot + fighting highest upside |
| MVP | 3 chars, 1 arena, basic ranked |

**Risk:** TSBG / RIVALS competition — need strong clip hook.

## 5. +1 Panic Room

| | |

| Social | Race friends, trap placement vote |
| Gap | +1 obby wave 97%+ ratings but room for sabotage twist |
