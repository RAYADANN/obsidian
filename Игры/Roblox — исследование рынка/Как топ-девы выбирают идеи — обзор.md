# Как топ-девы выбирают идеи — обзор

> Часть: [[00 — оглавление]]  
> Не «интуиция fun», а **система проверки signal до и после прототипа**.

---

## Главный принцип (общий для всех)

> **Идея не «хорошая», пока игроки не показали интерес — цифрами или органическим контентом.**

Топ-девы **не угадывают hit**. Они:
1. Копят backlog / смотрят gap на рынке
2. Делают MVP за дни–недели
3. Смотрят метрики
4. **Kill или scale**

---

## Три модели (см. [[Три модели выбора идей]])

| Модель | Кто | Суть |
|---|---|---|
| **A. Backlog → prototype → kill/scale** | Jandel, Nathan Clemens, Twin Atlas | ~200 идей на полке, refine годами, прототип = truth |
| **B. Acquire → improve** | Voldex, Do Big, Jandel (частично) | Покупают игру с traction, масштабируют |
| **C. Genre gap + distribution** | Wonder Works, SpyderSammy, Grandma's Favourite | Trend + twist + clip/co-op + live ops |

---

## Универсальный pipeline

```
1. INSPIRE    → backlog, тренды, gap, личный excitement
2. FILTER     → Roblox-native? social? scope? differentiation? content runway?
3. PROTOTYPE  → MVP за дни–недели
4. MEASURE    → CCU, session time, D1/D7, opt-in (Dubit)
5. COMMUNITY  → playtests, organic influencers
6. DECIDE     → scale / pivot / acquire / kill
7. LIVE OPS   → weekly updates, content для creators
```

Подробнее: [[Dubit — 4 фазы валидации]] · [[Чеклист — оценка идеи перед dev]]

---

## Чем это НЕ является

| Миф | Реальность |
|---|---|
| «Придумай уникальную механику» | Чаще: **twist на работающем жанре** |
| «Сделай красиво → взлетит» | **Retention + distribution** важнее polish |
| «Маркетинг после релиза» | Clip moment и co-play **закладывают до dev** |
| «Доработаю полгода без игроков» | **Kill rule:** нет аудитории к концу dev cycle → стоп |

---

## Kill rules (цитаты и практика)

**Jandel** (Naavik):
> *«Выпусти прототип. Если theme + gameplay цепляют — люди будут играть. Если никто не играет — не работай над этим.»*

**Nathan Clemens** (Naavik):
> *К концу dev cycle нет аудитории = fundamental flaw, stop noodling.*

**Grandma's Favourite Games** (DevForum):
> *«Know When to Move On… You don't know what new idea you're missing out on, by holding onto an old one.»*

---

## Что НЕ работает как core retention

- **Сюжетные главы** — one-and-done, низкий replay
- **Echo / campaign** без параллельных целей (collection, prestige, events)
- Pure mining sim без social/clip/trend hook (2026)
