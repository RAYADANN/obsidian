# Три модели выбора идей

## Модель A — Backlog → Prototype → Kill/Scale

**Кто:** Jandel, Nathan Clemens (UndoneBuilder), Twin Atlas (rapid division)

### Процесс
1. **~200 идей** на «полке» — фичи из других игр, свои наброски
2. Refine **1–3 года** (или месяцы для rapid division)
3. MVP / прототип
4. **CCU и session time** = truth
5. Нет игроков → kill

### Фильтры
- Roblox-native (social, без туториалов, без лора)
- **Differentiation** — нельзя «сделать то же, но лучше» (first-mover advantage)
- Fun to work on (Jandel) ИЛИ top-down profitability (Nathan)

### Примеры
| Игра | Как выбрали |
|---|---|
| The Survival Game | 3 года refine механики из старой игры |
| A Dusty Trip | Купили при 4–5k CCU, сломанный lobby → 70–80k за 2 недели |
| Grow a Garden | Партнёрство при ~500 CCU, retention уже был |

## Модель B — Acquire → Improve

**Кто:** Voldex, Do Big Studios, Jandel (когда покупает)

### Процесс
1. Scouting: organic discovery, dev submits link + metrics
2. Фильтр: **exponential growth potential**
3. Покупка / partnership
4. Live ops, marketing, retention layer
5. Мало greenfield ideation

### Фильтры (Voldex)
- Existing DAU / plays / growth inflection
- Можно улучшить через ops без ломания IP
- Команда понимает категорию

### Фильтры (Do Big)
- COO покупает только то, что **лично нравится**
- Strong foundation + gaps in marketing/retention/monetization

### Примеры
| Игра | Как выбрали |
|---|---|
| Brookhaven | Crown jewel acquisition, 60B+ visits |
| Driving Empire | Scaling phase → #1 car game |
| Steal a Character → SAB | Sammy купил права, добавил brainrot + PvP steal |

## Модель C — Genre Gap + Distribution

**Кто:** Wonder Works, SpyderSammy, Grandma's Favourite Games

### Процесс
1. **Gap analysis** — жанр растёт, но quality/механика слабая
2. **Twist** — один поворот на знакомое
3. **Distribution designed in** — clips, influencers, FOMO
4. Быстрый цикл: **4–6 недель** (Wonder Works)
5. Weekly live ops с day one

### Фильтры (Wonder Works)
- Underserved genre **with earning proof** (не пустой жанр)
- IP / theme **cuts noise** (SpongeBob TD)
- Mechanics → **3–4 influencer videos per update**
- D1, D7, ARPPU для алгоритма

### Фильтры (SpyderSammy / brainrot)
- **Trend timing** — мем уже viral на TikTok
- **One disruptive mechanic** (steal PvP на collection)
- **Developer-as-content** (Admin Abuse)

### Фильтры (Grandma's Favourite)
- Trend combo (survive X days + setting)
- **Small scope**, game jam → extend if fun
- «Make something you'd play» + YouTubers in head

## Какую модель выбрать solo-dev

| Ситуация | Модель |
|---|---|
| Есть код/опыт в жанре, быстрый test | **A** (prototype) |
| Нет аудитории, нужен signal за 2 нед | **A** или **C** (distribution-first) |
| Нашёл игру с 500–5k CCU и broken UX | **B** mindset (improve, не clone) |
| Видишь gap + trend window | **C** |
