# Чеклист — оценка идеи перед dev

> Часть: [[00 — оглавление]] · [[Dubit — 4 фазы валидации]]

Использовать **до** полноценной разработки. Идея «хорошая» только после signal.

---

## Phase 0 — 30 минут (desk research)

- [ ] **Genre CCU per game** — не total CCU ([[Market Friday — gap analysis]])
- [ ] **Trend direction** — rising or dying? (CCU Δ week-over-week)
- [ ] **First-mover moat** — can you be #2 with twist, not #5 clone?
- [ ] **Clip test** — explain in 15 sec TikTok without voiceover?
- [ ] **Co-play hook** — friends in same session by design?
- [ ] **Replay without story** — collection / prestige / random / events / PvP?

**Kill if:** saturated clone (escape brainrot −78%), story-as-core, no clip angle.

---

## Phase 1 — Graybox (1–3 days)

**Goal:** opt-in / desire (Dubit phase 1)

- [ ] Playable core loop in **<1 week** build
- [ ] Private / unlisted test with 10–50 players
- [ ] **Session time** on graybox — target genre benchmark
- [ ] Watch: do they **come back** same day without asking?

**Kill if:** Jandel rule — nobody plays prototype.

---

## Phase 2 — Soft launch (2 weeks)

**Goal:** D1 / early D7 (Dubit phase 2–3)

| Metric | Check |
|---|---|
| D1 | vs genre benchmark |
| Session length | first session >5 min |
| Bounce | first-play bounce not catastrophic |
| Organic | any clips / shares without paid promo? |

**Kill if:** Nathan rule — no audience by end of dev cycle.

---

## Phase 3 — Scale decision

- [ ] D7 trending right direction
- [ ] D28 path visible (progression + live ops plan)
- [ ] **Weekly update cadence** planned (RFY 28d)
- [ ] Monetization **doesn't break co-op** ([[Roblox — исследование идей/Shelf Shift — монетизация]] as template)
- [ ] Distribution: Admin Abuse / events / influencers **only if organic works**

---

## Red flags (auto-pause)

- «Like X but better»
- 6-month polish before first player
- Lore / campaign as retention core
- Pure brainrot escape in 2026
- No weekly ops plan post-launch
