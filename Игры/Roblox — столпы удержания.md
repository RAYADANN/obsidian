# Roblox — столпы удержания

> Часть: [[Механики удержания — обзор]]

Creation — **один столп**. В успешных Roblox-играх почти всегда **стек из 3–5 столпов**.

---

## Карта механик

| Столп | Суть | Roblox-примеры | Сила |
|---|---|---|---|
| **Progression** | Числа растут, открывается новое | Simulators, Blox Fruits | ★★★★★ |
| **Collection** | Собрать редкое / полный сет | Pet Sim, Adopt Me, ores/pets | ★★★★★ |
| **Creation family** | Построить / вырастить / изменить | Grow a Garden, Bloxburg, Mining | ★★★★☆ |
| **Idle / Offline** | Прогресс без онлайна | Grow a Garden | ★★★★☆ |
| **Social** | Друзья, trade, steal, flex | Grow a Garden, Adopt Me | ★★★★☆ |
| **Events / FOMO** | «Сейчас или никогда» | Grow a Garden weekends | ★★★★★ |
| **Prestige / Rebirth** | Сброс → навсегда сильнее | Все simulators | ★★★★☆ |
| **Exploration** | «Что там дальше?» | Doors, Deep Signal, biome unlock | ★★★★☆ |
| **Narrative / Mystery** | «Что случилось?» | Doors, Deep Signal Echo | ★★★☆☆–★★★★★ |
| **Tension / Horror** | Страх, adrenalin | Doors, Pressure, Deep Signal | ★★★★☆ |
| **Skill / Mastery** | «Я стал лучше играть» | Arsenal, Rivals | ★★★☆☆ |
| **Gambling / RNG** | Яйца, мутации, rare drop | Eggs, Grow a Garden mutations | ★★★★★ |
| **Status / Leaderboard** | Я выше других | Simulators top cash | ★★★☆☆ |

## Tier S — доказанные формулы

| Игра | Доминирующий столп | Creation в каком виде |
|---|---|---|
| **Grow a Garden** | Cultivation + Idle + Events | Сад как canvas + layout optimization |
| **Pet Simulator X** | Collection + Progression | «Создание» команды питомцев (loadout) |
| **Adopt Me** | Customization + Social | Дом + питомцы = expression |
| **Bloxburg** | Construction + Roleplay | Чистое строительство |
| **Brookhaven** | Social sandbox | Минимум progression, максимум freedom |
| **Doors / Pressure** | Horror + Exploration | Нет creation — доказательство, что creation не обязателен |
| **Mining sims** | Transformation + Progression | Копание = изменение мира + depth unlock |

## Паттерн успеха на Roblox

```
Простой core loop (понятен за 60 сек)
    +
Сильный feedback (звук, частицы, +цифры)
    +
2–3 параллельных цели (не одна)
    +
Что-то «моё» (plot, pet, garden, depth record)
    +
Причина вернуться завтра (daily, offline, event)
```

---

## Ключевой инсайт

На Roblox **Progression + Collection + Events** часто приносят больше CCU, чем чистое creation — потому что:
- creation требует **больше арта и UX**
- progression масштабируется **таблицами и конфигами**

Grow a Garden победил не «потому что сад красивый», а потому что совместил **7 столпов** одновременно.

→ [[Grow a Garden — разбор]]

---

## Roblox creation = guided creation

Не «сделай что угодно», а «сделай красиво *внутри рамок*».

Trade-off: меньше freedom, больше dopamine/minute.

→ [[Minecraft vs Roblox — creation]]
