# 01 — мета-паттерн (7 слоёв)

> Часть: [[00 — оглавление]] · Канон: `docs/starter-pack/01-meta-pattern.md`

Повторяется в ~90% топ-50 (июль 2026). Различаются **обёртка** и **комбинация engines**.

---

## Семь слоёв

```
HOOK      → Понятно ЧТО делать без туториала (0–10 сек)
LOOP      → Одно действие + feedback (каждые 3–30 сек)
GROW      → Валюта → сильнее loop
CHASE     → Цель, которую нельзя закончить
SOCIAL    → Другие игроки = часть прогресса
RESET     → Rebirth/prestige → новый chase
RETURN    → Причина зайти завтра
```

**Минимум 4 из 7** для 5k–15k CCU. Для 50k+ — **6–7**.

---

## HOOK

| Хорошо | Плохо |
|---|---|
| Steal a Brainrot | Epic Mining Adventure RPG |
| +1 Speed Keyboard Escape | Deep Underground Simulator |
| 99 Nights in the Forest | The Last Expedition |

## LOOP

Мгновенный отклик: звук + число + VFX.

**Dubit rule:** core action не enjoyable в прототипе без прогрессии → игра мертва.

## GROW

Награда усиливает loop: больше урона, слотов, множителя — **не декор ради декора**.

## CHASE

Mythic 0.01%, speed 999M, shift 47/∞, коллекция 847/∞. **D30 живёт здесь.**

## SOCIAL

Trade, steal, co-op roles, vote, hangout.

## RESET

Prebirth → Evolution → Ascension. Permanent multiplier + новая зона.

## RETURN

Offline accumulation, scheduled event, fear of loss, co-op appointment.

---

## Формула потенциала

```
ПОТЕНЦИАЛ =
  Hook(10с)           × понятен verb?
× Loop                × приятен feedback?
× Grow                × виден прогресс?
× Chase               × есть ∞ цель?
× (Social ИЛИ Session stakes)
× Return timer        × причина завтра?
× Mobile polish
× Thumbnail = правда
```

| Цель CCU | Нужно |
|---|---|
| 5k–15k | 5–6 множителей |
| 50k+ | 6–7 + viral |
| 500k+ | все 8 + cultural moment (E7) |
