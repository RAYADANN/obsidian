# 02 — семь engines (E1–E7)

> Часть: [[00 — оглавление]] · Канон: `docs/starter-pack/02-seven-engines.md`

**Engine** = самодостаточный retention-двигатель. Хиты комбинируют **2–4**. Один engine = узкий потолок.

---

## Таблица

| ID | Engine | RETURN | Топ-50 |
|---|---|---|---|
| **E1** | IDLE | «Накопилось, зайду» | ~14 |
| **E2** | NUMBER | «1.5M → 2M» | ~12 |
| **E3** | COLLECTION | «Нет mythic» | ~22 |
| **E4** | SOCIAL | «Друзья онлайн» | ~18 |
| **E5** | SESSION | «Ещё одну смену» | ~16 |
| **E6** | SKILL | «Стану лучше» | ~14 |
| **E7** | CULTURE | «Все играют» | ~5 overlay |

---

## E1 IDLE
Пассивный доход, offline. GaG, Brainrot, Pet Sim.  
**2026:** высокая конкуренция — нужен unique noun.

## E2 NUMBER
Stat += action → rebirth. Keyboard Escape, Drain the Lake.  
Число **всегда на экране**.

## E3 COLLECTION
Hatch/catch/roll → tier → flex. Adopt Me, Fisch, GaG mutations.  
**Обязательно:** reveal moment (VFX + sound + banner).

## E4 SOCIAL
RP, trade, steal, vote. Brookhaven, Adopt Me, Brainrot.

## E5 SESSION
Раунды, co-op stakes. 99 Nights, Animal Hospital, MM2.  
**Тренд 2026:** растёт быстрее IDLE-клонов.

## E6 SKILL
PvP, mastery. RIVALS, Blox Fruits, Tower of Hell.  
**Насыщенные полки.**

## E7 CULTURE
Overlay, не standalone. Brainrot memes, cozy TikTok.  
**Риск:** окно закрывается.

---

## Сильные комбо (solo, 40 дней)

| Комбо | Пример |
|---|---|
| **E5 + E3 + E4** | Animal Hospital, Fire Shift |
| **E5 + E4** | 99 Nights |
| **E2 + E7** | Keyboard Escape |
| **E1 + E3 + E4** | Brainrot |

## Слабые комбо

| Комбо | Проблема |
|---|---|
| E1 alone | «Ещё один сад» |
| Story only | D30 = 0 |
| E6 alone без E3 | Мало long-tail |
| E4 alone | Нужна критическая масса |

---

## Как выбрать

1. **Primary RETURN:** E1, E2, E5 или E4
2. **Secondary D30:** обычно E3 или E2
3. **Social layer:** trade, co-op, steal-lite
4. Проверь RETURN timer (слой 7)
