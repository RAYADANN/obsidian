## 10-секундный HOOK

Игрок понимает **без текста**:
1. **Что делаю?** (verb)
2. **Что получу?** (награда / число / редкость)
3. **Почему интересно?** (опасность / соревнование / милота)

---

## Thumbnail rules 2026

| Правило | Почему |
|---|---|
| Один фокус | Читаемость в сетке |
| Высокий контраст | Discover scroll |
| **Обещание = правда** | Bounce → RFY штраф |
| 3 thumbnail A/B | Разные hooks |
| Нет мелкого текста на 512×512 | Нечитаемо |

### Рабочие overlay (1920×1080)

- `SOMETHING IS WRONG HERE`
- `+1 SPEED EVERY STEP`
- `SHIFT 47 — CAN YOU BEAT IT?`
- `MYTHIC PULL` (скрин момента)
