# 07 — процесс создания хита

> Часть: [[00 — оглавление]] · Канон: `docs/starter-pack/07-how-to-design-a-hit.md`

---

## Фазы

```
Phase 0 — Idea scorecard     (1–2 дня)   → MECE ≥ 55
Phase 1 — Core prototype     (3–7 дней)  → Loop enjoyable
Phase 2 — Retention layer    (2–3 нед)   → D1 mechanics
Phase 3 — Polish + social    (1–2 нед)
Phase 4 — Launch + LiveOps   (ongoing)
```

**Не пиши код до Phase 2 gate** (graybox passed).

---

## Phase 0
- [[09 — idea checklist scorecard]] или [[../Фундамент/Алгоритм MECE Score — оценка набора механик|MECE /100]]
- Primary + secondary engine
- Core verb одним словом
- RETURN timer
- Thumbnail sentence

## Phase 1 — Graybox
- Placeholder art, только verb + feedback
- 5–10 playtesters
- **Kill if:** session < 1.5 min, «хочешь ещё» < 50%

## Phase 2 — Retention
| Система | Priority |
|---|---|
| Currency + sink | P0 |
| Collection/rarity | P0 |
| Return timer | P0 |
| Rebirth/milestone | P1 |
| Co-op/trade-lite | P2 |

## Phase 3 — Polish
- 3 thumbnails, reveal VFX, mobile UI, sound pass

## Phase 4 — LiveOps
- Weekly mini-event minimum
- Bi-weekly thumbnail refresh if CTR drops
