## Voice model — one brand, three registers

**CORE:** Solo indie. Multiverse. Honest updates. Free rewards for support.

| Площадка | Register |
|---|---|
| Roblox Group | Core + simple + emoji + play/group/favorite CTA |
| Discord | Core + lore (Transmission, Wanderer, Portal) |
| YouTube | Core + dev transparency + timestamps |
| Game Page | Core + EN SEO features (no lore) |

---

## Roblox Group post formula

```
[Emoji] HEADLINE
2-3 sentences — what it means for player.
✨ Feature list (3-6 bullets)
🎁 Bonus (if any)
👉 Game link · 👍 Like & Favorite
💬 Feedback call
— Zeon Studio
```

Shout = 2–4 lines max.

---

## Discord (#signals)

```
📡 **TRANSMISSION #XXX — TITLE**
1-2 sentences.
• Change bullet
▶ Portal: [link]
✦ Stay tuned, Wanderer.
```

Promo codes → #drops. Bugs → #glitches. Ideas → #beacons.
