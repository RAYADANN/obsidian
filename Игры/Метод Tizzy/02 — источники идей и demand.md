## Off-platform источники

| Источник | Что искать | Зелёный сигнал | Пример из канала |
|---|---|---|---|
| **CrazyGames** | Popular / 3D Unity | votes 50k–200k+, gameplay videos с views | Airport Security |
| **Addicting / Coolmath / Newgrounds** | Flash classics | ratings/plays, nostalgia loop | Jacksmith → The Forge |
| **Steam** | wishlists, sales, upcoming | 10k–200k+ wishlists / M+ sales | Totally Secure Airport; Mecha Chameleon |
| **Xbox Game Pass** | console hits | reviews + «можно упростить для kids» | Quarantine Zone → border games |
| **TikTok challenges** | viral challenge → minigame | миллионы views challenge | Bomb Click, Lying Challenge |
| **iOS / Play Store** | chart / meme apps | downloads M+ | bubble fake → Roblox port |
| **Minecraft / GMod** | minigames | YouTube demand + «где поиграть?» | Prop Hunt → Hide or Die |
| **YouTube comments** | «where can I play?» | gap у younger audience | Cole Hide or Die story |

### Как читать сигнал

1. Число (votes / wishlists / downloads / views)  
2. Контент-креаторы играли (лучше years ago → demand был, свежей версии нет)  
3. Можно ли **dummy down** для Roblox kids?  
4. Есть ли уже сильная реализация **той же фантазии** на Roblox?

## On-platform источники

| Источник | Что искать | Зелёный | Красный |
|---|---|---|---|
| **Creator Exchange / Search** | топ по ключу фантазии | 1–2 слабых / другой поджанр (RP) | 5+ сильных клонов |
| **RoTrends** | top moving, CCU vs visits | high CCU / low visits, recent, buggy, no updates | front-page clone farm |
| **Rolimons / RobloxGo** | CCU history | steady mid CCU niche | dead spike meme |

### RoTrends-фильтр (Steal before blow up)

Искать игру-донора для **study**, не для 1:1 clone:

1. Высокий **CCU относительно visits**  
2. Релиз **недавно** (или mid-size evergreen)  
3. Жанр **easy-to-dev** (если цель — быстрый win)  
4. Dev **редко апдейтит** + баги в feedback  
5. CCU на **uptrend до пика** (как акция)

Потом: play **2 часа**, не 10 минут → loop, progression, mono, bugs.
