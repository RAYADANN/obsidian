## Три океана на Roblox

| Океан | Смысл | Риск | Действие |
|---|---|---|---|
| **Blue** | Новая фантазия, почти нет игр | Высокий (нет proven demand) | Только если off-platform demand железный |
| **Red** | Saturated clones, одинаковые title/thumb | Высокий (CTR/Discover death) | Kill или **mutate** |
| **Purple** | High demand + **poor execution** | Средний | **Целевая зона Tizzy** |

```
PURPLE = demand (visits / CCU / off-platform)
        + weak current games (RP-only, buggy, stale, 1 old dominator)
```

## Фазы рынка (мутации)

```
Phase 1  First to market     → съедает share
Phase 2  Clone flood         → большинство умирает
Phase 3  Survivors mutate    → новый title + thumb + twist
```

**Выживают мутанты**, не чистые клоны:
- Don't Wake the… → Don't Steal the Bobo (тот же loop, новые metadata)
- Fishing: Ice / Cage fishing живут дольше Untitled Fishing Tycoon

### Mutate checklist

| Рычаг | Вопрос |
|---|---|
| Title | Не выглядит как 50-й «My X Tycoon»? |
| Thumbnail | Оригинал, не template metadata? (Roblox режет non-unique) |
| Theme twist | Ice / night / job / extraction — не тот же skin? |
| Subgenre | RP → checkpoint / extraction / co-op mission? |
| Audience | Underserved? (пример: adult first responders в Emergency RP) |

Official docs (по Tizzy): unique metadata; template-like experiences **понижаются** в recommendations.

## Как найти purple ocean (10 мин)

1. Взять **фантазию** (firefighter, airport, supermarket…)  
2. Creator Exchange → sort visits  
3. Записать: сколько сильных игр? какой **поджанр** доминирует?  
4. Off-platform demand? ([[02 — источники идей и demand]])  
5. Вердикт:

| Вердикт | Условие |
|---|---|
| **PURPLE — GO** | Demand есть + execution слабая / другой поджанр |
| **RED — MUTATE OR KILL** | Много клонов + сильный #1 без +20% twist |
| **BLUE — ONLY IF** | Off-platform demand доказан цифрами |

## Gap score (0–10) для шаблона

| Балл | Значение |
|---:|---|
| 0–3 | Red / нет дыры |
| 4–6 | Есть щель, нужна сильная мутация |
| 7–8 | Purple: 1 слабый доминант или RP-полка |
| 9–10 | Явная дыра + off-platform proof |

Примеры из канала: Firefighters ~высокий gap; Airport checkpoint vs RP; Secure the Airport call.

Примеры vault: Shelf Shift gap ~5/10 (Scary Grocery); Fire Shift ~8/10.

## Kill rules (Tizzy-side)

- Нет off-platform **и** нет on-platform mid demand  
- Red ocean без mutate-плана  
- «Ещё один sim» без twist  
- Копируешь #1 front page 1:1
