## Readable = уже «натренировано»

Игроки Roblox видели системы на миллиардах visits. Если твоя система **работает как у топа** (не обязательно выглядит 1:1) — onboarding дешевле.

| Система | Proven-якорь | Что копировать |
|---|---|---|
| HUD / side buttons | Grow a Garden | Принцип доступа к системам |
| Base lock | Steal a Brainrot | «дверь/лок = защита лута» |
| Incremental board | Cut Grass / sims | Buy 1 + **Buy Max** |
| Plot layout | GaG 2 | Spacing plots |
| Floating islands / bridges | Bedwars | Separation + skill moment |

**Не копировать 1:1 ассеты/title/thumb.** Копировать **функцию системы**.

### Checklist «readable?»

Для каждой системы в идее:

```markdown
- [ ] Система: ___
- [ ] Proven game: ___
- [ ] Visits/CCU якоря: ___
- [ ] Игрок уже знает verb? да/нет
- [ ] Mobile-friendly? да/нет
```

Если >30% систем «никто так не делал на Roblox» — либо гениальный risk, либо onboarding hell. Для solo default: **readable core**, novelty в fantasy/twist.

## Pareto 80/20 (+20% identity)

```
80% = proven loop / layout / systems
20% = своя идентичность (theme, map twist, 1 fresh verb nuance)
```

Пример Tizzy: GaG2 plot spacing + Bedwars sky islands → Build a Base map (не «ещё один flat steal»).

Связь с MECE: **C10 +20% differentiation** — тот же принцип, формализованный.

## Death by a thousand cuts (UX)

Мелкий friction суммируется → chore, не fun.

| Friction | Фикс (пример) |
|---|---|
| Spam Buy 1 | Buy Max / Buy 100 |
| Большая карта + лодки | Меньше map, bridges |
| Tutorial не = title | Первый шаг = promise (lock base, не build) |
| Не играл на телефоне | Playtest на phone обязателен |

**Хак Tizzy:** дать двоюродному брату телефон, **не объяснять** правила, смотреть 5–10 мин.
