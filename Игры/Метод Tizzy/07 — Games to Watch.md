# Games to Watch — тренировка intuition

> Часть: [[00 — оглавление]]  
> Источник: [Only the top 1%…](https://www.youtube.com/watch?v=0pMW1T0rdUI)  
> **Зачем:** качать game design intuition **без** ожидания своего ship каждый месяц.

---

## Цикл (еженедельно)

```
1. RoTrends → выбрать 1–3 up-and-coming игры
2. Play 30–120 мин (не 5 мин)
3. Notes V1 + hypothesis: CCU ↑ или ↓? почему?
4. Через 7–14 дней: Notes V2 — hypothesis true/false?
5. Записать урок → калибровка Tizzy/MECE
```

---

## Что смотреть в сессии

| Линза | Вопросы |
|---|---|
| **FTUE** | Цель ясна ≤60–120 сек? Curiosity loop открыт? |
| **Progression** | Чувствуешь progress в первые 5 мин? |
| **Social flex** | Видно чужой прогресс без zoom-out ада? |
| **Loop** | Fun без тяжёлой meta? |
| **Retention bait** | Причина вернуться завтра? |
| **Friction** | Где chore? |
| **Mono** | Когда и за что просят Robux? |

## Правила

- Ошибаться = ок; **разбор ошибки** = ценность  
- Не заменяет launch своих игр  
- 5 игр/месяц лучше, чем 50 поверхностных  
- Связь с dual: хорошие lessons → правки весов в [[05 — Tizzy Scorecard]] и MECE calibration
