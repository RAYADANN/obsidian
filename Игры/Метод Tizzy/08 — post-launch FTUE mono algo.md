## 2. Sticky first, monetize second

Порядок Tizzy:

```
Sticky loop (collection / PvP / session stakes)
    → retention green-ish
        → consumable mono experiments
```

### Consumables > eternal passes (для spend days)

| Продукт-тип | Зачем |
|---|---|
| 24h base lock | Повторные покупки, 7-day spend days |
| 2× offline / cash timed | Тот же рычаг |
| Pain-point at POI | Prompt там, где friction максимален |

Gamepass оставляй для identity/VIP; **не** превращай все boosts в one-time, если хочешь spend-days.

Loop: **data → hypothesis → update → measure** (как в Improve Stats FAST).
