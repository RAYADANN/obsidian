> **Цепляет** — мгновенный feedback + понятный verb + эмоция (радость / страх / surprise).  
> **Удерживает** — бесконечный chase + return timer + (social OR session stakes).  
> **Хит** — 1 core loop + 2–3 meta механики + 1 social слой.
