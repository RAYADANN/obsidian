# Tier-лист механик Roblox 2026

> Часть: [[00 — оглавление]]  
> Ранжирование по **силе на платформе** (июль 2026), не по «интересности в вакууме».

**Критерии ранга:**
- **Hook** — притягивает нового игрока (thumbnail, D1, clip)
- **Retention** — возвращает D7–D28
- **RFY fit** — работает с алгоритмом 2026 (return days, co-play)
- **Solo feasibility** — реализуемо за 40 дней одному

## B-Tier — работает в combo, слабо solo

| Механика | Проблема solo | Нужен partner |

| **Deep construction** | Art/UX cost | Customization + social flex |
| **Full trading day 1** | Dupes, scams | Retention proof first |
| **Story / campaign chapters** | D30 ≈ 0 | Wrap in M9 codex + events |

## Тренд 2026: что **растёт** vs **падает**

| ↑ Растёт | ↓ Падает / saturated |
|---|---|
| Co-op job + anomaly (E5+E3) | Pure E1 garden clone |
| Session survival + friends | Generic mining sim |
| Incremental + unique verb | «Like GaG but underwater» |
| Brainrot + **other** mechanic | Pure brainrot steal/escape |
| Horror-lite + progression | Story campaign core |
| Secret prestige / hidden zones | Polish-first, no loop |
