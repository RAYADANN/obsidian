# Выбор механик для своей игры

> Часть: [[00 — оглавление]]  
> Decision tree: какие механики взять **для твоего** проекта.

---

## Шаг 1: Выбери primary CORE (один!)

```
Что игрок делает каждые 3–30 сек?

[A] Action → number (+coins, +damage)     → C1 Click/Action
[B] Step/stat incremental (+1 speed)     → C2 Incremental  
[C] Job task (scan, sort, rescue)        → C3 Job loop
[D] Survive round / night / shift        → C4 Session
[E] Fight / aim / combo                  → C5 Skill
[F] Dig / break / explore                → C6 Transform
[G] Roleplay / hangout                   → C7 RP
```

**Solo 2026 recommendation:** C, D, or F (🟢 полки) over A/G (🔴/mass needed).

---

## Шаг 2: Выбери HOOK mechanism (один!)

| Если CORE = | Лучший HOOK |
|---|---|
| C1/C6 click | Rare drop flash OR satisfying SFX |
| C2 incremental | Big number on screen |
| C3 job | Anomaly «wrong» moment |
| C4 session | Near-death / last-second save |
| C5 skill | Kill clip / combo |
| C6 explore | First scare OR rare ore |
| C7 RP | Flex moment (weak solo) |

**Test:** можно ли это на thumbnail?

## Шаг 3: Выбери 1–2 META (retention)

**Обязательно минимум одно из:**

| Need | Pick |
|---|---|
| CHASE (∞ goal) | M1 Collection OR M2 Gacha OR M9 Codex |
| RETURN (завтра) | M4 Idle OR M5 Timer OR M3 Prestige tease |

**D28 requirement (RFY 2026):** добавь M5 Events OR M3 Prestige layer 2.

---

## Шаг 4: SOCIAL (опционально но +30% D30)

| Solo scope | Pick |
|---|---|
| Low (recommended) | S6 Leaderboard + friend bonus |
| Medium | S1 Co-op 2–4 roles |
| High (v0.2) | S2 Trade OR S3 Steal-lite |

**RFY 2026:** intentional co-play = отдельный сигнал. Хотя бы friend join bonus.

## Шаг 5: Проверь quadrant

| Твой stack | Quadrant | Action |
|---|---|---|
| Strong hook + strong D28 meta | ✅ POWERHOUSE | Ship |
| Weak hook + strong meta | SLEEPER | Fix CORE/HOOK first |
| Strong hook + weak meta | FLASH | Add META before polish |
| Strong hook + story only | ❌ HOOK TRAP | Add collection/prestige/events |

## Быстрые presets (solo dev)

### Preset «Fire Shift»
- CORE: C3 Job (rescue, extinguish)
- HOOK: Anomaly on dispatch cam
- META: M9 Codex + shift # (M5 night cycle)
- SOCIAL: S1 Co-op roles
- Score target: ~80/100

### Preset «Deep Signal v2»
- CORE: C6 Dig → extract
- HOOK: Stalker scare + signal spike
- META: M9 Echo codex + M3 Deep Reset + M5 Signal Storm
- SOCIAL: S6 depth leaderboard (+ S1 co-dig v0.2)
- Score target: ~70/100 after events added

### Preset «+1 [Noun]»
- CORE: C2 Incremental
- HOOK: Number overlay
- META: M3 Rebirth + M1 side collection
- SOCIAL: S6 race leaderboard
- Score target: ~75/100 if noun unique

### Preset «Avoid» (Deep Digger as-is)
- CORE: C1 click mine
- HOOK: Generic ore pop
- META: M3 rebirth + M1 pets (no events, no social)
- SOCIAL: none
- Score: **~28–35/100** — ❌ HOOK TRAP / 🔴 полка (не «55 prototype»)
