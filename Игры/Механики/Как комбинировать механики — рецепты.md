# Как комбинировать механики — рецепты

> Часть: [[00 — оглавление]]  
> Проверенные **стеки механик** из топ-50. Не invent — **combine**.

---

## Формула стека

```
CORE (1)     — что делаешь каждые 3–30 сек
HOOK (1)     — эмоциональный spike (reveal / scare / +number)
META (1–2)   — chase + return
SOCIAL (0–1) — co-op / trade / steal / flex
LIVE OPS (1) — weekly injection (events, new data rows)
```

**Минимум viable stack:** CORE + HOOK + 1 META + LIVE OPS plan

LIVE OPS: Weekly new anomaly type (1 data row)
