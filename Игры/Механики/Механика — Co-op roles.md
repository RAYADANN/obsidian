# Механика — Co-op roles

> Часть: [[00 — оглавление]] · Social: **S1** · Engine: **E4** subset

## Суть
2–4 игрока с **разными способностями/информацией**. Один не может пройти solo — нужна координация.

## Core verb
`coordinate` · `cover` · `call out` · `rescue`

## Что цепляет
- **Info asymmetry** — dispatch видит то, что engine не видит
- **Shared panic** — scream in Discord
- **Hero moment** — «I saved you at last second»

| Hook сила | ★★★★★ (with horror/job partner) |

## Что удерживает
- **Friend appointment** — «we play Tuesdays»
- **Role mastery** — «I'm best dispatch»
- **RFY intentional co-play** signal 2026

| D1 | D7 | D28 |
|---|---|---|
| ★★★★ | ★★★★★ | ★★★★★ |

## Design rules

| Rule | Why |
|---|---|
| **1 player ≠ complete** | Forces co-op |
| **Roles ≠ paywall** | Security cosmetic OK, not stun |
| **Asymmetric info** | Creates conversation |
| **Short session** | 5–20 min per shift/round |
| **No role hard-lock** | Swap roles between rounds |

## Solo dev

| | |
|---|---|
| **Complexity** | **High** (netcode, sync, balance) |
| **MVP hack** | 2P minimum, 2 roles, simple sync |
| **Fallback** | Solo + «AI partner» with delayed info |

## Лучшие комбо

| Partner | Why |
|---|---|
| Job / Shift | Natural role split |
| Horror / Anomaly | Panic amplifier |
| Session survival | Base building roles |
| Collection | «You hatch, I trade» |

## Anti-patterns

- Co-op cosmetic only (everyone same job)
- 8-player requirement (matchmaking hell)
- Griefing roles (pay-to-stun)
- Co-op without voice/text cues
