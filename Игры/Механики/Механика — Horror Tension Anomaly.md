# Механика — Horror / Tension / Anomaly

> Часть: [[00 — оглавление]] · Trigger: **E7** · Core: C3/C4/C6

## Суть
**Страх, напряжение, «что-то не так»** — adrenalin как hook. Не обязательно combat.

## Sub-types

| Sub-type | Gameplay | Пример |
|---|---|---|
| **Round horror** | Survive → escape | Doors, Pressure |
| **Anomaly detection** | Spot the fake | Animal Hospital |
| **Avoidance horror** | Hide from entity | Deep Signal Stalker |
| **Asymmetric** | 1 monster vs many | Forsaken |
| **Nextbot chase** | Run from meme NPC | Evade |

## Что цепляет
- **Adrenaline spike** — controlled, not annoying
- **Curiosity** — «what IS that?»
- **Mastery** — «I learned the rules»
- **Clip gold** — scream compilations

| Hook сила | ★★★★★ |

## Что удерживает

| Sub-type | D28 |
|---|---|
| Round replay (random) | ★★★★ |
| Anomaly catalog + shifts | ★★★★ |
| Avoidance + depth progression | ★★★ (+ needs events) |
| Story-only horror | ❌ |

**Critical:** horror hook **must pair** with collection/shift/prestige for D28.

## Feedback requirements

| Sense | Use |
|---|---|
| **Sound** | Primary channel (footsteps, whispers, direction) |
| **Light** | Darkness, flashlight, vignette |
| **Timing** | Predictable rules → fair scares |
| **Camera** | Shake sparingly (0.02–0.05) |

Deep Signal insight: **sound > visuals** for solo dev horror.

## Solo dev

| | |
|---|---|
| **Art cost** | **Low** — dark environment cheaper than bright sim |
| **Scope** | Avoid combat AI — use timing + sound |
| **MVP** | 1 entity, 1 rule, 3 scare moments |

## Лучшие comбо

| Partner | Recipe |
|---|---|
| Job loop | Anomaly among tasks |
| Co-op | Info asymmetry panic |
| Collection | Entity/biome codex |
| Exploration | Depth = more danger |
| Events | «Blood moon night» |

## Anti-patterns

- Jump scare every 30 sec → desensitize
- Combat horror on MVP → scope death
- Story-only → one-and-done
- Unfair random deaths → rage quit
