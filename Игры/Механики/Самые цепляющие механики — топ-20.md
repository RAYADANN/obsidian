## Критерии «цепляющей» механики

```
ЦЕПЛЯЕТ =
  Понятность за 3–10 сек (verb clarity)
× Мгновенный feedback (< 0.5 сек)
× Эмоциональный spike (joy / fear / surprise)
× Shareability (clip за 3–15 сек)
× «Ещё один раз» без принуждения
```

## Пять «движков эмоций» (почему мозг не отпускает)

### 1. Variable Ratio Reinforcement (слот-машина)
**Механики:** hatch, RNG drop, mutation, aura roll  
**Сила:** ★★★★★ hook + ★★★★★ retention  
**Риск:** frustration если слишком rare без near-miss

### 2. Loss Aversion (страх потери)
**Механики:** steal, base decay (99 Nights), sanity meter  
**Сила:** ★★★★★ D1, ★★★☆☆ D30 (churn risk)  
**Риск:** toxic community, rage quit детей

### 3. Competence Loop (мастерство)
**Механики:** +1 speed, skill PvP, anomaly detection skill  
**Сила:** ★★★★☆ hook, ★★★★☆ D30  
**Лучше с:** visible number или rank

### 4. Relatedness (социальное)
**Механики:** co-op panic, trade, flex garden, voice RP  
**Сила:** ★★★★☆ hook, ★★★★★ D30  
**RFY 2026:** intentional co-play — отдельный сигнал

### 5. Curiosity Gap (неизвестность)
**Механики:** anomaly «what is it?», depth, lore fragment, secret zone  
**Сила:** ★★★★★ D1, ★★☆☆☆ D30 **solo**  
**Fix:** wrap in collection codex (M9)

## Feedback — без этого механика мёртва

| Уровень | Что нужно | Пример |
|---|---|---|
| **Micro** | Sound + particle на каждое действие | Coin pop, crack sound |
| **Meso** | Screen feedback + number animation | +500 float, speed tick |
| **Macro** | Camera shake, flash, banner, cutaway | MYTHIC reveal, flashover |
| **Social** | Visible to others, chat-worthy | Steal notification, flex |

**Правило Dubit:** если core action не enjoyable **без** прогрессии в graybox → механика не работает.

---

## Hook decay — когда перестаёт цеплять

| Механика | Hook lifetime | Почему |
|---|---|---|
| Cultural meme (E7) | Weeks–months | Trend dies |
| Story twist | Once | Seen it |
| Hatch reveal | **Years** | Variable ratio never gets old |
| +1 number | Months–years | Number ceiling raises |
| Anomaly types | Months+ | If new types added (live ops) |
| Steal drama | Years | New victims = new clips |

## Чеклист: твоя механика цепляет?

- [ ] Verb понятен из названия?
- [ ] Первый feedback **< 1 сек** после spawn?
- [ ] Эмоция (joy/fear/surprise) в первые **60 сек**?
- [ ] Можно снять clip **3–15 сек** без объяснения?
- [ ] Игрок повторяет action **без подсказки**?
- [ ] Thumbnail = этот moment?

**< 4 галочек** → механика не hook, только meta.
