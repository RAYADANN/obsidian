## Три уровня механик

```
MICRO   — одно действие (клик, удар, шаг, scan)
    ↓
CORE    — повторяемый loop (dig→sell, shift→survive, hatch→flex)
    ↓
META    — долгосрок (collection, rebirth, events, trade)
    ↓
SOCIAL  — между игроками (co-op, steal, trade, flex)
```

**Хит = 1 CORE + 2–3 META + 0–1 SOCIAL** (минимум).

## Анатомия одной механики (шаблон карточки)

Каждая карточка в этой папке следует формату:

```markdown
## Суть (1 предложение)
## Core verb
## Что цепляет (hook/emotion)
## Что удерживает (RETURN/CHASE)
## D1 / D7 / D28 сила
## Feedback requirements (SFX/VFX/UI)
## Roblox примеры + CCU tier
## Solo dev: сложность / art cost
## Лучшие комбо с другими механиками
## Anti-patterns
## MVP minimum spec
```
