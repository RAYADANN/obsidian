# Психология механик

> Часть: [[Механики удержания — обзор]]

Почему [[Creation — семейство механик|семейство creation]] и другие механики так сильно цепляют.

---

## Self-Determination Theory (SDT)

Три базовые потребности, которые игры могут закрывать:

| Потребность | Что это | Как закрывает creation |
|---|---|---|
| **Autonomy** (автономия) | «Я сам решаю» | Свобода формы, расположения, стиля |
| **Competence** (мастерство) | «Я умею, я расту» | От кривой хижины до красивой базы |
| **Relatedness** (связь) | «Меня видят / я часть группы» | Показать сад, базу, скин, питомца |

**Creation бьёт сразу по трём из трёх** — редкая комбинация.

Для сравнения:
- **Кликер** → в основном competence
- **PvP** → competence + relatedness
- **Чистый сюжет** → relatedness + curiosity

## Дополнительные триггеры

### Endowment effect
То, что *я* построил / вырастил, ценится сильнее, чем купленное или выпавшее из коробки.

### IKEA effect
Усилие при создании повышает привязанность к результату. «Я сам собрал» > «мне дали готовое».

### Visible progress
Изменения в мире **видны глазами**, а не только как цифра в HUD. Пространственная награда запоминается дольше.

### Ownership
«Это *мой* участок / *моя* шахта / *мой* сад» — эмоциональная собственность поверх абстрактной прогрессии.

## Мотивации игроков (Quantic Foundry, упрощённо)

| Мотивация | Лучшие механики |
|---|---|
| **Completionist** | Collection, albums, 100% journal |
| **Builder** | Construction, layout, customization |
| **Optimizer** | Rebirth math, pet loadouts, mutations |
| **Explorer** | New biomes, depth, secrets |
| **Socializer** | Trade, flex, co-op, steal/gift |
| **Thrill-seeker** | Horror, PvP, rare RNG |
| **Relaxer** | Idle, cozy cultivation, no pressure |

**Creation family** сильнее всего у Builder + Completionist + Relaxer.

**Simulators** сильнее у Optimizer + Completionist + Thrill-seeker (RNG).

На Roblox аудитория смещена к **Completionist + Optimizer + Socializer** (12–16 лет) — отсюда доминирование pet/egg/rebirth, а не чистого Minecraft-style building.

## Вывод

Creation — мощный *носитель* удержания, потому что даёт **эмоциональную собственность** поверх абстрактной прогрессии.

Но creation не единственный путь к ownership:
- коллекция = «мой музей»
- prestige = «мой статус»
- narrative = «моя история»
