# Формула игровой петли

> Часть: [[Механики удержания — обзор]]

Универсальная модель затягивающего цикла — для любой механики, не только creation.

---

## Базовый цикл

```
Действие игрока
    → Немедленный feedback
    → Награда / изменение состояния
    → Ощущение роста / ownership
    → Новая возможность / цель
    → (повтор)
```

**Creation добавляет уникальный слой:** награда не только «+100 coins», но и **«мир изменился и это видно»**.

---

## Типы наград

| Тип | Пример | Эмоция |
|---|---|---|
| **Числовая** | +500 Sheckles | Краткий dopamine |
| **Предметная** | Rare pet | Коллекционный thrill |
| **Пространственная** | Новая комната в шахте | Discovery |
| **Творческая** | Красивый участок сада | Pride, ownership |
| **Социальная** | Друг украл урожай → история | Memorable moment |
| **Narrative** | Новый Echo-фрагмент | Curiosity |

**Самые sticky игры комбинируют минимум 3 типа награды за один цикл.**

---

## Минимальный sticky stack для Roblox

```
1 primary loop     (action → reward)
+ 1 ownership      (my X)
+ 1 long-term goal (collection OR prestige)
+ 1 return trigger (daily OR offline OR event)
+ strong feedback  (VFX/SFX every action)
```

Creation — **опциональный**, но если добавляешь — выбери **один** sub-type из [[Creation — семейство механик]] и доведи до конца.

---

## 5 вопросов при проектировании

1. **Какой sub-type creation?** (build / grow / dig / customize / collect)
2. **Что игрок «владеет»?** (plot, pet, depth record, journal)
3. **Виден ли прогресс глазами?** (не только HUD)
4. **Есть ли offline / daily hook?**
5. **Есть ли social story?** (что игрок расскажет другу)

## Grow a Garden — эталон петли

```
Plant → Water → Harvest → Sell → Expand → (repeat, но с новыми tiers)
```

Каждый шаг = instant feedback (sparkle, sound, coin burst).

Петля **эволюционирует**: новые crops, mutations, gear — не просто повтор.
