## Главный вывод (синтез всех исследований)

> **Топ-10 Roblox ≠ одна гениальная механика.**  
> Это **стек из 4–7 слоёв**, где каждый слой закрывает свой горизонт retention (D1 → D7 → D28),  
> **signal проверяется до polish**, а distribution закладывается в дизайн.

**Формула:**
```
ХИТ = HOOK (притяжение)
    × LOOP (удовольствие каждые 3–30 сек)
    × STACK (2–4 engine + return timer)
    × SIGNAL (D1/D7/D28, clips, co-play)
    × SHIP (MVP ≤ 40 дней, weekly live ops)
    × (удача / cultural moment — необязательно, но для 500k+ нужна)
```
