## Блок 7: Спорные / переоценённые тезисы

### ❌ Слишком категорично

| Было в research | Коррекция |
|---|---|
| «Paid YouTuber бесполезен» | **Seed** для retrieval/explore возможен. Бесполезен как **замена** retention |
| «Pure mining sim не работает 2026» | Работает с **E5/E7 twist** (tension, anomaly, depth horror) — Deep Signal path |
| «Creation редко доминирует solo» | Верно для **CCU sims**; Bloxburg evergreen proves creation + social works at lower CCU |
| «≥28/35 = prototype» (Obsidian checklist) | Desk score **не заменяет** graybox signal. MECE добавляет Phase 2 gate |
| «Top-10 = все 7 слоёв + E7» | **Необходимо но недостаточно** — cultural moment / timing / luck для 500k+ |

### ⚠️ Нюансы

| Тезис | Нюанс |
|---|---|
| Doors/Pressure без creation | Доказывает alternative path через **E5 + exploration + tension** |
| Narrative в Deep Signal | Может работать **если** wrapped in E3 (Echo codex) + events |
| D1 benchmark 25–30% | Sim vs horror vs RP — разные пороги |
| Roblox «novel games» push (RDC 2025) | Opportunity для RPG/strategy, но **retention rules те же** |
